# 0.2.1 验证记录 · 2026-10-29

## 已通过项

- **类型与词典检查**：核心客户端、桌面端与浏览器扩展的 TypeScript 类型检查全部通过，OneTHU 中英文词典校验通过。
- **课程字段解析测试**：覆盖官方未读计数、课序、上课时间与地点解析；缺失或异常计数统一保留为“未知”。
- **桌面与窄屏模拟测试（1600×1000 / 390×844）**：验证进入学堂自动呈现工作台首页、三栏内容分布、官方统计数字、课程计数及学期切换。
- **界面与状态持久化**：核对官方双行 Logo 结构、导航 SVG 图标、截止提示色、明暗外观切换、课程筛选、过期通知展示，以及置顶和忽略状态在刷新后的保留效果。
- **作业与课程内容交互**：覆盖作业详情、多附件解析、富文本 HTML 清洗，以及模拟环境下的附件上传与作业提交；确认服务端拒绝提交时会保留当前编辑内容，提交成功后会回读最新状态。同时覆盖通知正文与附件、课件地址、讨论阅读与模拟发送回复、内嵌课程服务窗口。
- **真实浏览器登录态联调**：在真实登录态下实测首页读取、作业与附件详情、提交表单渲染以及课程答疑页加载。

## 测试环境说明与已知情况

为避免向线上课程写入测试数据，提交作业、移除已交附件和讨论发帖等写操作均通过模拟接口完成验收；后续若学校端调整表单规则或服务接口，可按实际页面跟进适配。课程信息、答疑、问卷、邮件、在线课堂、收藏与备注模块直接内嵌学校原站页面，完整保留原站原生表单与交互功能。

本机 Chrome 重新加载 0.2.1 后已完成实页核对：官方 Logo、导航与课程页 SVG 图标、首页三栏布局与提示色、作业提交表单、附件去重以及内嵌课程服务均显示正常，原页面外层滚动条及内嵌服务的旧版页头、侧栏均已收起。

停留在内嵌课程服务子页时直接刷新浏览器，本机 Chrome 偶发出现空白窗口。目前已增加一次自动重试、加载状态反馈与“重新加载”按钮，实测点击“重新加载”即可恢复正常显示，后续可继续优化该直刷场景的加载稳定性。
