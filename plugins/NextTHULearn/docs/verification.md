## 验证边界

未使用真实账号执行作业提交、移除附件或发帖，写操作由模拟接口验收。真实学校表单规则和后续服务变动仍可能要求调整。课程信息、答疑、问卷、邮件、在线课堂、收藏和备注使用内嵌学校页面，保留原生功能而非独立实现接口。

Chrome 已重新加载 0.2.1，实页核对官方 Logo、导航与课程页 SVG、首页三栏和提示色、作业提交表单、附件去重及嵌入课程服务。原页面滚动条、内嵌服务的旧页头与侧栏已收起。

课程服务停留后刷新，在本机 Chrome 中曾出现空白窗口。已增加一次自动重试、加载反馈和“重新加载”操作；实测手动重新加载可恢复。该刷新场景尚未稳定通过，因此不标为原生页面的完全对齐。
