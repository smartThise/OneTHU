# OneTHU 术语与动作约定


本文整理英文界面的默认术语口径。简体中文为产品源文案，其他语言按实际含义翻译，品牌名保持原样。

| 中文 | 英文 | 说明 |
| --- | --- | --- |
| 首页 | Home | 固定译为 Home，避免使用 My Whiteboard |
| 白板 | Board | 用户可自由摆放组件的画布 |
| 组件 | Widget | 首页/白板可添加的元素 |
| 工作区 | Workspace | 一组标签页 |
| 标签页 | Tab | 包含首页标签 |
| 我的 | Me | 用户设置入口 |
| 我的名片 | My card | 个人资料卡 |
| 通讯录 | Contacts | 好友与组织入口 |
| 暂存箱 | Stash | 全站统一用词，注意与云盘回收站 Trash 区分 |
| 口令 | Share code | 用于读取分享内容的凭证码，注意与账号密码 Password 区分 |
| 短口令 | Short share code | 联网取回内容的短码 |
| 碰一碰 | Tap to share | NFC/近距离分享 |
| 一级功能区 | Main features | 首页功能入口 |
| OneShot | OneShot | 保留品牌原名，避免改译为 Dock |
| 极简模式 | Minimal mode | 极简固定首页 |
| 实用模式 | Practical mode | 精简日常使用 |
| 完整模式 | Full mode | 白板、工作区等全部功能 |
| 网络学堂 | Web Learning | 学校教学平台专名，注意与课程学习动词 Learn 区分 |
| 雨课堂 | Rain Classroom | 独立作业源 |
| 日程 | Schedule | 课程、作业截止及个人安排 |
| 课表 | Timetable | 课程时间表 |
| 待办 | Tasks | 个人待办事项，与学校作业 Assignments 区分 |
| 作业 | Assignment | 学校课程作业，避免译为 Task |
| 截止时间 | Due date / Deadline | 截止状态用 Due / Overdue |
| 清华云盘 | Tsinghua Cloud Drive | 学校云盘存储服务 |
| 组织 | Organization | 包含成员、角色与资源权限的协作组织 |
| 负责人 | Owner | 组织最高权限角色，注意与 Admin、Member 区分 |
| 石墨 | Graphite | 默认主题 |

| 动作或状态 | 英文 | 必须保留的区别 |
| --- | --- | --- |
| 生成口令 | Create share code | 创建新的分享口令 |
| 复制口令 | Copy share code | 仅复制现有口令文本 |
| 接收 / 导入 | Receive / Import | 将分享内容保存到本地 |
| 存入暂存箱 | Add to Stash | 存入暂存箱以便后续引用 |
| 取用 | Open / Use | 按上下文选用 Open 或 Use，取用后原条目仍保留在暂存箱 |
| 删除记录 | Delete record | 仅清除本机记录 |
| 撤销分享 | Revoke share | 联网使远端分享链接或口令失效 |
| 已保存 | Saved | 已写入本机，尚未确认远端同步状态 |
| 已同步 | Synced | 远端服务端已确认写入成功 |
| 待同步 / 待重试 | Pending sync / Retry needed | 仍在等待同步或需要重试，需如实体现未完成状态 |
| 无权限 | Access denied | 明确表达权限受限，与资源不存在（Not found）区分 |
| 尚未确认 | Not confirmed | 结果仍待确认，避免译为已成功或已失败 |
| 断开连接 | Disconnect | 仅断开本机连接，远端内容保持不变 |
| 退出登录 | Sign out | 退出当前设备的账号会话 |
| 前往 | Open | 打开对应的课程或作业标签页 |
| 寻迹 | Directions | 前往上课地点的路线导航 |
| 整包更新 | App update | 下载完整安装包并由系统安装，与热更新（live update）区分 |

清华院系、课程名称与教师姓名等专有名词优先采用学校官方译名；无官方英文名称时直接保留中文原文，避免自行意译。
