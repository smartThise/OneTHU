# OneTHU 0.11.4 · Revolution


[English](en/release-0.11.4.md) · [下载](https://github.com/smartThise/OneTHU/releases/tag/v0.11.4)

此次更新打通了 OneTHU CLI、常驻后台任务与 OH 的应用内能力，并汇集了近期针对登录、云盘、通知附件与界面交互的多项修复。

- **OneTHU CLI 与 SDK**：支持独立安装使用；macOS 与 Windows 桌面端内置 Node 运行时，与应用共享登录态、定时任务及执行历史。已授权的后台任务在关闭主窗口后仍可继续运行，支持课程与资料查询、归档、定时检查、通知及 MCP 接入，可通过命令目录查看当前支持的完整操作项。
- **OH 工具**：接入应用能力目录与调用接口，支持在对话中查询 OneTHU 好友、组织成员和共享资源，管理项目与公告，检索清小搭技能、向已选智能体提问，并读取、收纳及分享暂存箱内容；涉及角色授权等变更时引导至管理页确认。
- **雨课堂**：OH 与 CLI 统一支持雨课堂查询，独立维护校园主会话与雨课堂会话，清晰展示分页状态、部分加载提示与无截止日期的任务项。
- **稳定性**：修复 IM 配置与对话上下文文件的并发冲突，完善请求取消与运行锁机制，优化桌面端与 CLI 的会话移交、云盘自动连接及多账号隔离。
- **学习与界面**：修复通知附件的文件名解析与格式识别；合入玻璃材质效果、壁纸打包归档、多标签页及 OH 面板交互优化。

在平台运行方式上，macOS 与 Windows 支持独立 Node 常驻后台，Android 端继续采用移动端内嵌 OH；好友、组织、白板与暂存箱等本地界面能力需在应用运行期间调用（独立 CLI 会动态列出当前环境下可调用的命令），依赖本地桌面环境的重型技能仍可导出交给外部 Agent 运行。

自动执行任务沿用本机授权策略，修改、分享与外发操作均经过权限与当前账号核验；模型回答由所配置的提供方生成，当上游模型服务返回异常时会如实记录错误状态以便排查重试。

三端正式版本均为 **0.11.4**；Android ARM64 版沿用原正式签名证书与 Logo，versionCode 为 **11013**。
