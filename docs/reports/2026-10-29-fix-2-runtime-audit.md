# 0.11.4-fix-2 实现与验收记录

> 最后更新：2026-11-18 01:30

## MadModel

对照本地 DSH 插件的 `lib/engine.js` 与 `lib/toolfix.js` 实现：DSH 将令牌维护与模型调用解耦，模型画像的响应与空闲预算设为 120 秒，空工具回复回补预算设为 180 秒。此前 OneTHU 等待响应头上限为 60 秒，将状态不明的超时归入可重试，且聊天预检会同步等待有效令牌提前续签；在校园服务高负载慢响应时，这会拉长对话等待并增加重复请求压力。

本次调整将响应头与流式空闲预算统一放宽至 180 秒；仅对连接建立失败执行有限次重试，状态不明的超时及已开始输出的请求直接结束本轮。遇到 429 限流时优先遵循 Retry-After，未提供时至少退避 5 秒，并让后续发往学校模型的请求共享该等待窗口。学校模型（含回环与隧道转发）共用支持取消的进程内排队通道；近期验证通过且有效期充足的令牌直接用于发起对话，路由探测与提前续签改为后台异步完成。

遇到临时认证故障时继续保留本地已有凭据，并通过账号世代检查拦截跨账号的滞后写回。上述改动已在本地模拟服务下完成对齐验证，实际对话响应耗时还将随校园服务的实时负载与网络状况波动。

## 应用、OH 与 CLI

OH 的内部服务目录与任务接口统一走 `app` 通道，依据智能体许可、学校账号及操作权限完成鉴权，并清理了学习资源服务、任务通知与雨课堂同步中遗留的外部 CLI 开关检查。外部入口继续受独立开关与写操作确认保护；原生下载权限对应已授权的应用服务，权限撤销或策略变更时自动中止旧世代写入。

CLI 默认优先连接正在运行的应用以读取实时应用服务，独立常驻宿主则读写同账号的本地 profile；已启动且版本一致的独立 CLI 可由桌面端直接接入。界面相关的本地能力通过动态目录对外列出，独立插件、模型提供方及独立 IM 入站配置则由各自宿主分别管理。

GUI 日历文档与 SDK 的日历、邮箱配置映射到同一份账号记录：首次迁移按 UID 合并，日常文档写入附带内容版本号；卸载时保存当前基线，重装后自动合并离线期间的新增、修改与删除记录。多账号数据彼此隔离，相同记录若出现双端修改矛盾，会完整保留源数据并上报冲突。已授权的云盘连接与雨课堂会话经由私有桥接共享，用户在独立端手动修改过的凭据不会被桌面端刷新覆盖。

## 可选 CLI 包

macOS 与 Windows 的默认安装资源移除了内置 Node 与 CLI，Android 端继续采用应用内宿主。完整模式导览末页与 OH 设置页现提供 CLI 组件的安装、升级、重新安装与卸载操作；独立 ZIP 包内置 Node 与启动器，在未预装 Node 的终端环境下也可直接使用。

组件下载仅接受官方正式 Release 与现有清华云盘发布库，安装时逐项核对版本号、目标平台、资产 SHA-256、包内逐文件摘要、路径及解压总大小，校验通过后原子替换运行目录。卸载时先暂停全局唯一调度器、持久化任务与日程及会话记录、清理本组件开机自启项，再移除运行时文件，用户的账号 profile、执行历史与已下载文件均完整保留。安装状态切换期间会对日历写入和任务操作加锁，避免两个调度器同时执行。
