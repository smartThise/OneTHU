## MadModel

对照本地 DSH 插件的 `lib/engine.js`、`lib/toolfix.js`：DSH 将令牌维护与模型调用分开，模型画像的响应/空闲预算为 120 秒，空工具回复回补为 180 秒。OneTHU 原先等待响应头 60 秒，并把模糊超时列为可重试；聊天预检还会等待有效令牌的提前续签。慢响应下，这些行为会延迟对话并增加重复请求压力。

本次将响应头/流空闲预算调整为 180 秒；连接建立失败可有限重试，模糊超时及已开始输出的请求结束本轮。429 尊重 Retry-After，缺少时至少等待 5 秒，并让下一条学校模型请求继续遵守等待时间。学校模型（含回环/隧道）共用可取消的进程内请求通道。最近验证过且寿命充足的令牌直接用于聊天，路由探测与提前续签放到后台。

认证临时故障仍保留旧凭据，账号世代检查继续防止旧请求写回新账号。这里确认的是实现差异及模拟服务行为；校园服务的实时负载和网络条件仍会影响响应时间。

## 应用、OH 与 CLI

OH 的内部服务目录和任务接口使用 `app` 通道，授权来源为智能体许可、学校账号和操作权限。移除了学习资源服务、任务通知、雨课堂同步对外部 CLI 开关的残留检查。外部入口仍由独立开关和写确认约束；原生下载权限对应已授权的应用服务，撤销/策略变化继续取消旧世代写入。

CLI 默认优先连接运行中的应用，读取实际应用服务；独立常驻宿主使用同账号 profile。已启动、同版本的独立 CLI 可以被桌面接入。应用专属的 GUI 能力以当前目录为准；独立插件、模型提供方及独立 IM 入站配置仍按宿主管理。

GUI 日历文档与 SDK 日历/邮箱配置映射到同一份账号记录。首次迁移按 UID 合并，文档写入使用内容版本；卸载保存基线，重装时合并离线增加、修改与删除。不同账号隔离，相同记录的矛盾内容保留源数据并报告冲突。已授权云盘连接和雨课堂会话通过私有桥接共享，独立修改过的凭据不会被应用刷新覆盖。

## 可选 CLI 包

默认 macOS/Windows 安装资源移除 Node/CLI，Android 继续使用应用内宿主。完整版导览末页与 OH 设置提供安装、升级、重新安装、卸载。独立 ZIP 含 Node 与启动器，支持无需预装 Node 的终端使用。

下载只接受固定正式 Release 或现有清华云盘发布库。安装核对版本、平台、资产 SHA-256、包内逐文件摘要、路径和解压大小，原子替换运行目录。卸载先暂停唯一调度器、保存任务/日程/会话，清除本组件自启动，再移除运行文件；账号 profile、历史、下载文件保留。安装状态切换期间锁住日历写入和任务操作，避免两个调度器同时执行。
