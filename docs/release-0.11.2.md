# 0.11.2 修复更新


[中文](release-0.11.2.md) · [English](en/release-0.11.2.md)

本次更新覆盖 macOS、Windows 与 Android 三端，集中优化了网络学堂会话恢复、壁纸跨设备备份、平板触控编辑、玻璃材质表现与桌面窗口管理。0.11.1 用户可直接覆盖升级，现有数据与设置完整保留。

## 网络学堂会话

网络学堂现可根据响应内容准确区分会话过期、网关异常、权限受限与接口限流。并发请求共用同一次会话重连，作业详情的查看页与提交页合并为单次读取流程；遇到异常时给出重试入口并保留上一次完整数据，诊断日志全程略去密码、令牌、Cookie 与网页正文。

## 壁纸备份与恢复

新版壁纸备份一并打包图片或视频原文件、壁纸库记录与内置壁纸引用。两台设备均升级至新版后，在原设备上传备份，即可在另一台设备下载还原；媒体文件写入本机壁纸目录并通过校验后自动应用壁纸设置。

早先仅保存原设备本地路径的旧备份，可在仍存有原图的设备上升级后重新上传一次。单个媒体文件上限为 12 MiB，整份备份上限为 24 MiB；若云端尚无备份、权限受限或超出容量上限，界面会分别提示并保持当前壁纸不变。备份与恢复继续使用原有的手动入口和云盘授权。

## 平板与玻璃效果

横屏平板采用宽屏布局，并配有触屏设备的编辑锁定开关：日常浏览时可自由滚动页面与点开内容，点击「编辑」后再移动和缩放白板组件；切换白板、旋转屏幕或更改体验模式后自动回到浏览状态。

学习页筛选栏、通知条、作业卡片与详情标题统一采用玻璃材质，当前主题、玻璃强度与自动文字对比度设置同步生效。

## 桌面窗口与升级提醒

桌面正式版支持单实例唤醒，再次启动应用会直接唤回已打开的主窗口。OH 面板处于开启状态时，关闭主窗口会将其收起至后台，后续可通过 OH 重新唤出；主窗口与 OH 均关闭后应用退出（开发预览版保持独立运行）。在 Windows 上覆盖安装时，请允许安装器关闭旧版 OneTHU 进程，以清理残留窗口。

极简、实用与完整模式现共用统一的更新提示弹窗，支持直接查看新版说明并选择延后提醒时长，手动检查更新入口继续保留。Android 版沿用正式签名与原版 Logo，versionCode 升至 11011。

## 提醒、新闻与手机操作

更新延后提醒提供 1 小时、1 天与 7 天三档，重启应用后依然保留，并按版本号独立记录。三种模式下点击「前往更新」均可直达软件更新界面，且弹窗会等待当前打开的对话框与新手指引关闭后再展示。此外，校内新闻来源单位现按界面语言展示对应的中英文名称并分语言缓存；手机端组件确认按钮优化了手指微移容差，关闭面板时省去组件目录的重复渲染；简洁首页移除了重复标语。
