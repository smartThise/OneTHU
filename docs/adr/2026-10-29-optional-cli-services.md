# 应用服务为主体，CLI 为可选适配器

状态：已实现，正在验证安装产物与发布渠道。

原实现将外部 CLI 授权、OH 内部服务和桌面登录绑定到必装 Node 进程；SDK 与界面又分别保存本地日程。开关影响手机 OH，桌面与终端出现两份日程，安装包也附带用户未选择的运行环境。

应用内服务的权限来源是学校账号、OH 服务授权和各操作权限。外部入口另受 CLI 开关控制。常驻调度仍只有一个所有者：已安装 CLI 的桌面使用常驻任务，移动端及未安装的桌面使用应用内调度。故障不启动第二个调度器。

日历共享采用私有账号文档接口，SDK 和 GUI 读写相同事件及邮箱配置；既有数据迁移有记录，写入附带内容版本。私有接口仅主窗口可调用，不登记到 MCP/模型工具，凭据不会作为模型结果返回。GUI 内存通过刷新接收常驻变更。卸载前导出到应用存储，保留 CLI profile 以便重新安装。

CLI 安装是显式行为，独立 ZIP 的执行文件随正式 Release 分发。平台、版本、SHA-256、路径、解压大小和逐文件摘要均验证；安装原子替换，卸载走正常退出。外部访问开关与运行文件的安装状态分别呈现。
