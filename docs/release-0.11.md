# 0.11 Revolution


中文 · [English](en/release-0.11.md)

0.11 将视觉设计、自由工作台与体验模式整合为全新的 OneGUI 体系，全面升级多端导航、个人资料云同步、清小搭技能生态与新手导览。若同一版本号下发布了后续修订包，可通过「关于」页或诊断摘要中的构建提交号核对当前安装的具体版本。

## 主要变化

- 默认采用石墨色视觉体系，统一管理主题、排版密度、材质令牌与自动文字对比度。
- 提供极简、实用、完整三种体验模式；第 0 步先选择界面语言，随后按所选模式呈现功能导览。
- 三种模式均内置全局搜索、OneTHU Harness 与插件能力说明；完整模式进一步开放自由白板、暂存箱、短口令、NFC、组织管理与清小搭。
- 完整模式支持多白板画布、标签页、工作区切换、OneGO!、可配置 OneShot 导航及可自由拖放的刷新与暂存箱入口。
- 暂存箱支持长按拖入、落点高亮提示与统一分享入口，方便跨页面收纳和传递资料。
- 新增涵盖成员、文件、项目与公告的组织管理功能，并可通过私有个人资料库跨设备同步名片、好友与组织索引。
- 跨设备同步默认自动合并互不冲突的更新；遇到双端修改同一项的冲突时，通过对比卡片清晰呈现差异供二选一。
- 日程视图整合校内课程、作业截止与自定义安排，修复紧凑模式下的截止来源展示与底部滚动体验。
- 接入清小搭对话、历史记录、智能体与技能广场；OH 可直接加载兼容的参考资料与纯 JavaScript 技能。
- 优化登录设备指纹一致性、防重复认证、20 秒冷却、2FA 时序及脱敏错误诊断。
- 修复 Android 系统返回历史、手机端胶囊排版、Windows 建窗线程及网络学堂跨平台布局细节。

## 能力边界

**NFC 目前可用性不稳定，请尽量使用口令。** 应用内置的轻量技能运行环境面向参考资料与纯 JavaScript 技能；需要 Python、Node 或外部命令行服务的完整技能包（如前期抽查的六份工程样包）可导出至电脑端 Agent 运行。若在多校园账号协作、特定品牌 Android 后台驻留或不同桌面硬件环境下遇到兼容问题，欢迎附上脱敏诊断摘要反馈。

仓库 README、官网和文档中的所有配图均使用隔离的模拟示例数据生成，覆盖手机竖屏、平板横屏与桌面大屏视口，生成方式与复现命令详见 [预览素材](screenshots.md)。
