# 联网短口令

> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

> 最后更新：2026-11-18 01:30

按用户确认的方案，分享功能默认全面采用联网短口令，停用面向用户的离线长字符串生成，同时继续兼容导入旧版口令。

## 方案

直接复用清华云盘既有的分享凭据，无需额外部署短码服务器或维护公共映射表。标准的 20 位十六进制 token 会无损转换为 16 位易读 Base32，按四位一组加上 ON 前缀，总长固定为 22 个字符；非标准 token 则完整保留原始凭据，确保随机熵充足。名片、暂存箱和组织内容统一作为云端 manifest 上传，口令长度恒定，与分享内容的体积无关。

发起新分享需要发送方已连接清华云盘；接收方联网即可匿名读取分享内容，无需事先登录自己的云盘。分享的七天有效期与随时撤销均由云盘服务端控制。短码仅携带该次分享的访问凭据，剥离了登录 token、仓库 ID、私有目录路径与头像本体。历史版本的 ONV1/ONV2/ONTOUCH1/ONORG1 口令依旧可直接导入。

## 实施与验证

- [x] 共享短码编码、识别、解析与云清单发布：`lib/shortCode.ts` 负责 Base32 无损互转、Crockford 形近字符自动纠错与 ONX 非标准凭据兜底；`state/cloudExchange.ts` 负责 manifest 发布与匿名解析。遇到云盘拒绝目录分享时自动回退为分享单个 `manifest.json` 文件（`/f/` 链接），两种链接形态均可编码为短口令。
- [x] 暂存箱、个人名片、组织邀请与组合分享统一接入短码，NFC 与二维码载荷保持一致。名片与组织内容均通过云盘 manifest 承载，大图头像无需压缩裁剪，口令长度恒为 22 字符。
- [x] 所有接收入口兼容新旧口令并保留原有落盘逻辑。`receiveExchangeCode(text, vaultTarget)` 作为统一入口，让导入口令、收碰一碰、扫码、NFC、雷达和抽屉均能自动识别暂存箱、名片、组织与碰一碰四类载荷；原「替换当前箱」入口传入 `current`，延续既有覆盖行为。
- [x] 补齐口令长度、无损转换、大小写与分隔符容错、旧协议兼容、未连云盘/过期/损坏报错，以及跨独立客户端匿名读取测试。
- [x] 完成类型检查、浏览器界面验证与自动化回归，并同步更新长期记忆。

## 实施记录（2026-10-19）

**发布去重与稳定分享位。** `publishExchangeCode(code, contentKey, slotName)` 通过两层机制避免同一份内容反复上传：若内容摘要未变且旧口令仍可匿名读取，则直接复用原口令；对于名片、组织这类会持续更新的内容，采用稳定分享位（slot）就地覆盖同一云盘目录下的 manifest，既保持口令恒定、让对方随时读到最新内容，又避免每次修改都新建云盘目录。暂存箱与碰一碰组合属于快照分享，按内容摘要缓存即可；暂存箱会复用 `lastShareCode`，一旦箱内条目发生变更便自动清空重签。

**真机暴露的问题与修复。**
1. 读取报错 `Command seafile_share_read not found`：测试设备运行的是 10-11 构建的安装包，而该原生命令于 10-18 注册；切换至 dev 应用或重新打包安装即可解决。
2. 「导入口令」原先仅接受 ONV1/ONV2，粘贴名片或组织短码会报错「应以 ONV1. 开头」，现已接入统一解析入口并按载荷类型自动分发。
3. 重复接收同一张名片时，原逻辑将通讯录去重误判为失败并提示「没有可导入的内容」，现已改为明确提示「本地已有（未重复添加）」。
4. 平台形态判定曾将 1256×596 的桌面窗口误判为手机形态（因短边 596 < 600）：现改为「宽度 < 600 判为手机；高度 < 600 时需同时满足宽度 ≤ 960（横屏手机）才判为手机」，桌面窗口压矮时依然保持桌面布局，并补充 11 条单元测试固定规则。
5. 雷达首次分享提示「请先连接清华云盘」：小窗口形态未打开过暂存箱页导致云盘适配器尚未挂载，现由 `shareCodeForBox` 自动按需挂载。

**验收。** `tools/short-code-test.mjs` 57 条用例全部通过（涵盖编解码、定长校验、容错纠偏、旧前缀区分及 500 次随机抽样零碰撞）；`tools/short-share-browser-test.mjs` 50 条用例通过（基于模拟云盘运行两个独立客户端——发送方已连接、接收方纯匿名——覆盖生成、复用、更新、路由分发、旧协议兼容、过期、撤销与防篡改）；`tools/platform-test.mjs` 新增 11 条手机形态判定用例。既有的 `vault/org/namecard/mobile-vault/feedback-round2` 五套浏览器测试已同步适配模拟云盘、新短码格式及新版导航结构（设置入口迁入「我的」、组织迁入通讯录页）。雷达与抽屉两个小形态面板也补齐了「收口令 / 扫码」入口。

整套方案依托清华云盘运行，无需自建服务端；真实云盘跨账号互传留待后续使用 dev 应用或重打包版本在双账号真机上联调。
