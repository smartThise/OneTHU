# OH 应用能力接入


用户陆续反馈 OH 无法顺利发现雨课堂、好友与组织功能，并希望一并梳理清小搭及其他新增能力。排查发现，原有专用工具主要覆盖学校接口、白板与插件，好友、组织、技能广场和暂存箱尚缺公共查询入口，而既有的已启用技能检索也只面向本地已启用项，尚未覆盖完整的清小搭广场。

本次通过同一份经审核的服务目录向 OH 提供 `app_services` 能力发现与 `app_call` 调用入口，统一复用 CLI 的参数校验、账号代次核对、结果脱敏与写操作确认机制。应用内部调用直接走本机内部通道，无需用户开启面向外部的 CLI 监听；常驻任务等后台功能则继续按各自的 CLI 授权规则核验。所有可调用能力均须预先登记在公共目录中，每轮对话还会向模型动态注入宿主当前实际提供的操作名，在保留既有专用工具的同时让模型严格依据真实可用能力作答。

目录中现已补齐 OneTHU 好友名片、组织概览及成员／项目／公告／资源引用、清小搭智能体与技能广场／已安装技能／导入启停，以及暂存箱摘要与文本内容读取。好友与组织数据按当前登录账号、完整模式及个人资料归属逐层核验，组织远端详情还会实时校验成员权限；名片分享口令、组织通道密钥与邀请凭据在进入模型前均已剥离。报告同步汇总了现有的学校服务、白板、OneFlow、插件、主题与常驻任务工具，复杂的图形编辑、扫码登录与系统级权限授权则继续通过页面跳转直达完成。

验收覆盖了真实的好友查询、组织问答与技能广场能力发现，同时逐一测试了权限缺失、账号切换、模式切换、非法参数、取消确认与敏感字段过滤等边界场景。本轮完整保留已有的 CLI、雨课堂与附件相关修改，暂不发布新安装包。
