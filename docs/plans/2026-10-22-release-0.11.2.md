# 0.11.2 发布范围与验收


在 0.11.1 修订构建期间，发布目标调整为 0.11.2，一并纳入更新提醒、新闻语言适配、首页文案精简与手机端组件确认交互优化。已公开的 0.11.1 安装包保持原样，对应标签对齐至当时的发布源码，本轮面向三个平台重新构建 0.11.2。

## 行为约定

- 极简、实用、完整三种模式共用同一个更新提醒宿主，启动后以只读方式检查官方 GitHub 与清华云盘双源，发现新版本时弹出 OneGUI 提示窗。
- 点击「前往更新」直接跳转到软件更新区域，并复用已获取的版本信息；具体下载与安装仍由用户主动点击触发。
- 「暂时忽略」提供 1 小时、1 天、7 天三档选择。忽略期限按版本号保存在本机，重启后继续生效；到期后可在当前会话再次提醒，遇到更高的新版本时也会恢复提醒。
- 启动后延迟 3 秒执行首次检查，检查成功后每 6 小时轮询一次，失败后间隔 15 分钟重试。页面处于后台时等待回到前台再展示提醒，遇到新手导览、实践返回条或已打开的对话框时也会礼让在先。
- 更新提醒支持中英文切换、键盘 Escape 与 Android 系统返回，直接关闭弹窗等同于按当前选定的时长稍后提醒。
- 新闻单位直接展示学校门户在对应语言下的原始名称，中英文缓存分开保存；切换语言时会丢弃迟到的旧语言返回结果，文章正文则保持来源原貌。
- 移除简洁首页两句重复口号，保留「今日待办」与「今日课程」的标题及功能。
- 手机端「确认添加」按钮优化触摸识别，防止手指小幅晃动被误判为页面滚动；单次点击只执行一次添加，组件目录在退场动画期间保持稳定，避免重复挂载。

## 一并发布的修复

本轮同步包含学习会话恢复、壁纸媒体跨设备备份、横屏平板编辑锁、学习页面玻璃材质覆盖，以及桌面端 OH 单实例与窗口关闭逻辑等修复，详情参见同日的三份专项审查记录。

## 验收和发布

在不接入真实账号的浏览器测试夹具中，覆盖三种模式 × 中英文 × 手机／桌面视口，逐项验证提醒持久化与时间边界、软件更新跳转落点、新闻语言切换及确认按钮触摸交互。待类型检查、OneGUI 规范、i18n 检查与核心行为测试全部通过后冻结源码。

三个平台版本号统一设为 0.11.2，Android versionCode 为 11011，沿用正式签名证书与标准 Logo。Windows 与 macOS 通过 GitHub Actions 构建，Android 在本地完成签名构建。每个安装包均与 source、Actions ZIP 或本地签名记录一一对应，校验无误后新建 Release v0.11.2，同步更新清华云盘各系统目录、双源版本清单、官网中英文下载信息与在线文档，原 0.11.1 资产继续保留。
