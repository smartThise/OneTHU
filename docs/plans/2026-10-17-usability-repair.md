# 首页 / 白板 / 玻璃 / OH 可用性修复


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

用户反馈集中于以下体验问题：首页标题显示有误、100% 缩放下画布超出屏幕、鼠标滚轮被待办卡片截留、组件移动与缩放受阻、设置项说明重复、毛玻璃失去原有透光质感、OH 专属操作按钮出现在普通搜索与清小搭模式中，以及底部胶囊缺少按压回弹反馈。本轮逐项修复如下：

- 首页主标题统一显示为「首页」。
- 将 100% 缩放定义为适配当前页面宽度的基准视图：基准适配比例与用户手动缩放分离，所有拖拽、拉伸、组件落点与画笔轨迹统一按实际显示倍率换算；底层存储坐标维持不变，拖拽过程中基准比例保持稳定。
- 首页滑动待办卡片将普通纵向滚轮事件交还页面滚动，卡片自身的触摸滑动与独立待办页轮播保持原有交互。
- 桌面端恢复点击非交互卡体直接拖动与点选缩放；手机端浏览保持按阅读顺序纵向排布，点选卡片后通过浮动工具条执行上移、下移、增高与减高。
- 毛玻璃恢复原有的透光档位、模糊半径、饱和度与高光描边，继续保持配色与材质正交；保留文字与图标自动对比度引擎，修正现代 CSS 颜色函数解析与状态按钮锁色问题。
- 创造、新建、历史、导入导出与朗读按钮收敛为仅在 OH 模式下展示，收起按钮保持常驻；底部胶囊恢复指针与键盘按压回弹动效，并与输入框点击和语音手势互不干扰。
- 结合真实鼠标滚轮、免编辑模式直接拖拽、触屏指针、存量旧布局、多档窗口宽度、真实壁纸与文本对比度探针进行完整验证，同时通过实拍截图核对毛玻璃透光表现。

## 接手后的追加（2026-10-17 晚，本分支）

- 选中态收起：点击画布空白处（含世界层）、页面其他区域或卡片内部的按钮与输入框时均自动退出选中态；点击调节浮条与缩放手柄自身时保持选中。
- 开启壁纸时，首页标题板同步应用毛玻璃材质（`--og-fill-surface` + `--og-surface-blur`），自然透出底层壁纸色彩。
- 精简“编辑布局”独立模式：移除额外的拖拽把手、编辑布局/完成切换钮、配套提示文案与 `is-layout-editing` 样式；桌面端支持随时直接拖动，手机端采用纵向堆叠点选配合浮条微调。
- 画布空白处右键与点击「＋」统一打开同一个组件选择器（`BoardAddDrawer`）：提供缩略图网格、搜索框以及文件夹与 OnePage 专属入口，右键唤起时自动记住指针落点。
- 一并修复根目录 `pnpm build` 脚本问题（为 `packages/gui` 的 build 脚本补齐路径引号，消除含空格或特殊路径下的 sh 语法报错）。

## 第三轮反馈（23:03）

- 组件选择器恢复三段分组：常用（便笺置顶）/ OnePage 与组合 / 全部组件，支持跨分组即时搜索；抽屉顶部把手支持上拉展开全屏、下拉回到半高或收起关闭。
- 画笔墨色板精简为三色预设加撤销与清空按钮，让浮动工具条排布更舒展。
- 标签页图标全面对齐一级功能区 `NAV`：OnePage 标签展示自定义名称与专属图标，插件标签渲染插件自带的 `iconSvg`。
- 将全仓产品拼写统一规范为 `THUBook`（覆盖 UI 文案、文档、测试与 OH 工具描述；内部页面路由 ID 与源码文件名保持兼容不变）。
