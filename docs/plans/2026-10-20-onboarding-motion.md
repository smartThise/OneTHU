# 三种模式的空间导览与交互演示


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

2026-10-20 · `exp` · 起点 `98eb32f0`

## 目标与设计

将原有的静态说明卡片升级为沉浸式三维空间演示，对标主流硬件与消费级 App 产品短片的质感：突出手机机身与实体卡片的真实厚度、倒角、玻璃与镜头细节，配合柔和的环境光反射与连贯自然的相机推拉旋转。三维层采用按需延迟加载的 Three.js 实体几何与 PBR 物理材质构建；下方说明文字与功能直达按钮继续由稳定的 OneGUI 组件承载，早期的纯 CSS 立体卡片则保留为无 WebGL 环境下的降级方案。

- 极简模式：聚焦「今天」与「五个入口」，共两课。
- 实用模式：涵盖「今天」「更多功能」与「调整四个入口」，共三课。
- 完整模式：重点演示「白板」「暂存箱」「口令」「碰一碰」与「组织」，共五课；其余六个进阶主题收纳在尾页供用户按需探索。
- 模式选择页保留清晰直观的定位说明；切换模式仅调整界面组织形态，本地已有数据与各项偏好设置均完整保留。
- 舞台交互仅驱动本地演示状态，点击功能按钮则可真实跳转至对应业务页面；尾页扫码绑定依旧支持跳过，OH MCP 高级开关继续限定在完整模式下展示。
- 结合后续体验反馈，进入章节后舞台默认自动循环播放，仅保留简洁的暂停控制；当系统或应用开启「减少动态效果」时直接呈现稳定的静态画面。自动播放节奏与边缘退场的细节打磨见 [自动播放计划](2026-10-20-onboarding-autoplay.md)。

## 实施顺序

1. 抽离独立的课程配置与步骤导航模块，更新过时文案并完整保留原有的全部功能跳转落点。
2. 通过 `TourStudioScene` 与 `tourStudioModels` 构建真实三维几何、PBR 材质、连续运镜与支持随时反向接续的演示动作；由 `TourIllustration` 统一承接语义控制，`tour-scenes.css` 提供无 WebGL 时的图形降级。
3. 重整 `OnboardingTour`、`ExperienceModePicker` 与独立样式表 `tour.css`，实现常驻页脚、可回退步骤、尾页可选探索、真实页面顶部的返回导览条以及顺滑的方向过渡。
4. 清理旧版平面示意图样式并全面接入 OneGUI 配方，逐一适配矮屏、320px 窄屏与「减少动态效果」模式。
5. 更新并运行真实浏览器回归套件，人工逐张审视桌面与手机实拍截图，修正画面细节后提交。

## 视觉取舍与最终技术方向

迭代过程中曾先后尝试粒子光效版与纯 CSS 3D 版：用户审看后指出粒子与光效略显花哨，而纯 CSS 3D 又偏扁平、缺少连续实体感，希望向苹果设备短片那样干净克制的物理质感靠拢。最终定稿全面采用真正的 Three.js 三维几何、实体相机与 PBR 材质反射，并悉数撤去装饰粒子、光轨、霓虹底座与多重光圈：

- 白板章节：多层卡片在空间中自然展开、对齐排布并平滑收回。
- 暂存箱章节：箱盖轻巧掀开，内容卡片依次滑入收纳，原处卡片稳妥保留。
- 口令章节：发送卡片利落翻转生成短码，接收端卡片随之展开响应。
- NFC 章节：两台手机模型从侧背面流畅翻转至正面、彼此靠近轻触，随后从容归位。
- 组织章节：主组织名片向外舒展带出成员卡片，展示完毕后平滑收拢。
- 全局由单一持久化的三维舞台接管模型进出与相机无缝衔接；所有动作均支持中途反向过渡，快速连续切课时直接从当前空间姿态平滑转向最新目标，无需排队等待旧动画播完。单次常规动作时长控制在 1.4～2 秒；完整转身重播拆分为「拉远景别 → 旋转机身 → 推回近景」三段，并按整圈旋转包络体计算安全取景距离，消除中段边缘裁切出画。
- 手动暂停、滚出视口、窗口切后台以及开启「减少动态效果」时均有确定的稳定终态，且静态模式下所有页面交互照常响应。
- 零外部模型文件与网络图片请求，圆角几何体与屏幕纹理均在本地即时构建；按需启用必要的物理材质通道并限制最大 DPR，动画静止后自动停帧省电，WebGL 上下文意外丢失时支持自愈重建，组件卸载时完整释放几何体、材质、纹理与渲染器内存。
- 三维渲染包独立异步分块按需加载，外围控制栏与模式选择继续沿用轻量 OneGUI 组件；三维媒体画布赋予独立的语义色彩角色，与应用主题切换和自动对比度引擎和谐共存。

技术参考：[Three.js 物理材质](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[圆角几何](https://threejs.org/docs/pages/RoundedBoxGeometry.html)、[环境照明](https://threejs.org/docs/pages/RoomEnvironment.html)。

早期的粒子版与纯 CSS 3D 版记录了探索演进过程，最终交付品质以当前 Three.js 实体版本的运动序列帧、实录视频、四档视口截图及自动化回归结果为准。
