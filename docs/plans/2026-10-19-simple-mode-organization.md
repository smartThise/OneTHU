# 极简模式、组织管理与收发整理 Implementation Plan


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

**Goal:** 修复固定首页标签滚动叠字问题，统一暂存箱收发入口，完善组织工作区，并在完整保留完整模式存档的前提下新增极简模式与开屏导览。

**Architecture:** 极简模式使用独立的偏好键与临时导航状态，完整保留完整模式下的标签、白板和 OneShot 存档；公共内容页、OH 胶囊与原生接入流程直接复用。组织数据以组织记录作为唯一数据源，组织名片由其自动派生；文件存储复用现有清华云盘桥接，成员、项目与公告保存在组织记录中。

**Tech Stack:** React/TypeScript、OneGUI 语义与结构令牌、现有 Tauri/清华云盘桥接、Playwright 真实组件验收。

起点：`exp` / `945824c0`（dsh 短口令收尾已完成，直接在此基线上推进）。

## Task 1 固定首页标签
- [ ] 在 `packages/gui/src/recipes/workbench.css` 中为 sticky 首页标签补齐不透明底层，同时维持选中态与毛玻璃栏视觉；验证横向滚动标签栏时文字清晰无重叠。

## Task 2 独立模式和五入口
- [ ] 新增 `state/experienceMode.ts`，管理 full/simple 模式偏好、独立导航状态与模式切换事件，保持 explorer/board 原有存档原样不动。
- [ ] 更新 `quickAccess.ts` 默认快捷入口为学习/预约/生活/信息/课表，保留已有自定义配置；simple 模式固定展示这五个入口。
- [ ] 调整 `Layout.tsx`、`TabHost.tsx` 与 `BottomBar.tsx`：simple 模式仅挂载简洁外壳、固定首页与当前内容页，隐藏标签栏、OneGO、白板、暂存箱与名片入口；完整模式交互原样保留。
- [ ] 在真实浏览器中对比模式切换前后的完整模式本地存储、已开标签与白板布局。

## Task 3 极简首页、设置与导览
- [ ] 极简首页聚焦「今日待办」与「即将上课」两块核心信息，直接复用现有课程与待办数据组件。
- [ ] 提供精简版设置页，包含模式切换、基础账号登录、外观基础项、OH 自填 API 及微信/飞书扫码绑定；完整模式设置页同步提供模式切换入口。
- [ ] 新增开屏导览：按「选择模式 → 功能说明 → 可跳过的雨课堂/IM 接入」推进，完整保留本地已有数据且全程静默无外发消息。
- [ ] 保留 OH 与全局搜索能力，在 simple 模式下收起创造模式及高级工作台入口。

## Task 4 暂存箱收发
- [ ] 抽取共享收发操作组件，让雷达、抽屉与暂存箱标签页统一具备生成分享口令和接收口令能力，合并原先重复的「导入口令/收碰一碰」等同义按钮。
- [ ] 暂存箱标签页保留多箱管理与条目管理；组合分享收纳为独立可选项，让主收发流程保持清爽。
- [ ] 基于模拟云盘验证各入口的口令生成、复制、接收与 NFC 状态反馈。

## Task 5 组织工作区
- [ ] 在 `state/org.ts` 中扩展项目与公告持久化、成员角色与删除保护，以及组织名片自动派生逻辑。
- [ ] 在 `OrganizationSection.tsx` 组织详情页整合成员、文件、项目与公告四个分栏；文件分栏直接调用真实云盘接口完成列举、上传与删除。
- [ ] 调整 `NameCardSection.tsx`，取消单独新建组织名片的入口；历史名片数据继续兼容读取，新建组织后自动关联展示对应名片。
- [ ] 验证增删改查持久化、页面重载恢复、多组织数据隔离、名片同步及旧数据兼容，并明确记录跨账号云端同步边界。
