# OneTHU 0.11 README、官网与文档实施计划


> 归档说明：本文记录当时的实施计划与随批更新的验收进展；0.11 现行功能与使用说明请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

**目标**：将仓库 README、官方网站及全部现行用户与开发者文档同步更新至 0.11 实际交互与能力，并配套提供完全基于隔离模拟数据采集的手机竖屏、横屏与桌面大屏预览素材。

**架构**：主仓库统一维护工程文档、模拟数据截图采集器、来源哈希清单与媒体资产；独立官网仓库维护支持自定义外观说明的产品主页、滚动驱动的三维设备展示以及中英文双语 MkDocs 文档站，严格沿用原版上下排布 Logo。既有的设计方案、审计报告与技术调研作为历史档案保留，统一补充归档说明与现行文档入口，方便读者区分阶段性记录与当前正式功能。

**技术**：真实 React / OneGUI 组件配合 Playwright 隔离数据注入、静态 HTML / CSS / JavaScript、按需加载的本地 Three.js 模块，以及 Material for MkDocs。
