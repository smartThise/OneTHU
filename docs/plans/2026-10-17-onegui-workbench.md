# OneGUI Workbench — 第二轮视觉重构


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

收到第一轮界面变化不够明显的反馈后，本轮直接以真实首页、设置与搜索的整页渲染截图和实际交互体验作为验收准绳。

## 设计决策
- 石墨与暖纸工作台：清晰划分环境底、内容面、输入井与浮层四个表面层级，主要动作采用醒目的实心墨色按钮。
- 首页从悬浮覆盖式时钟与程序坞调整为自然文档流：工作台标题与时间 → 服务导航 → 自由画布；画布原有卡片数据、拖拽、缩放、笔迹与工作区完整保留。
- 拉开标题字阶并稳定阅读行宽，服务入口改为排版规整的图标导航；清理旧版圆球装饰、扫光特效、悬浮弹跳与重复嵌套边框。
- 设置页在桌面端采用左栏目右内容的双栏布局，手机端保留单行横滑栏目，原有栏目分类与搜索直达体验保持一致。
- OH 搜索按清晰的标题、输入框与结果列表组织；各类弹层、菜单和表单统一复用同一组 OneGUI 语义角色。
- 视觉样式统一收归组件库，清理过期的宿主外观声明并拦截新增硬编码色值；用户已有的画布组件摆位保持原位。

## 实施与验证
1. 重新梳理结构与表面语义角色，统一组件库控件密度和标题字阶。
2. 重排首页文档流结构、服务导航与画布工具栏，为新白板提供舒展的三列默认尺寸。
3. 落地设置双栏布局、OH 搜索、导航栏与浮层样式配方，清理相互竞争的旧样式。
4. 在真实浏览器中逐项验证亮暗主题、手机视口、横竖标签栏、设置栏目切换、搜索直达以及画布拖拽与本地存储兼容性。
5. 通过 typecheck、build、OneGUI 护栏与 CSS 解析检查，归档整页截图并记录验证边界。
