# 0.11.4-fix-2：统一应用服务与可选 CLI

## 目标和决定

OH 使用应用自身的服务目录与授权，外部 CLI/MCP 开关只管理外部入口。手机和未安装 CLI 的桌面保留应用内服务与任务。安装 CLI 后，桌面与常驻进程共用账号、任务及日历/邮箱数据；CLI 默认优先连接正在运行的应用服务，显式独立配置仍可使用。

CLI/Node 从默认桌面安装包移出，按平台发布独立 ZIP。完整版导览与设置提供安装、状态和卸载，下载来源固定为本项目正式 Release，核验平台、版本、资产摘要及包内逐文件摘要。卸载先关闭常驻进程并保存数据，只删除运行文件，保留用户账号与任务。

## 实施顺序

1. 对照本地 DSH MadModel 插件，修复慢响应重发、并发压力、阻塞续签，增加取消/429/空响应测试。
2. OH 内部任务调用与授权脱离外部 CLI 开关；保留写确认、账号世代和任务授权范围。
3. 增加私有、账号隔离的共享日历文档接口，将 GUI 和 SDK 映射到同一份事件/邮箱配置。首次迁移合并不同 UID，相同 UID 的不同内容报告冲突；写入使用版本检查，阻止覆盖并发修改。关闭应用后 CLI 继续访问同一份数据。
4. CLI 可选安装管理，默认薄包；更新导览、设置、中英文文案、独立包命令和 CI 验收。
5. 回归认证、移动 OH、日程双向写入、迁移/冲突/卸载，更新版本和报告，构建三端并核实发布渠道。

## 验收证据

- 本地模拟服务验证 MadModel 串行、取消与限流退避，真实账号不进入自动化测试。
- CLI 关闭时内部 OH 查询/任务可用，外部请求仍被拒绝；Android 无 Node 安装需求。
- GUI 新增、CLI 修改/删除、重新打开 GUI 均读到一致结果；账号切换/旧版本写入被拒绝。
- 未安装 CLI 可直接登录；安装失败不清会话；卸载保留数据且应用服务继续工作。
- CI 产物证明不含 Node/CLI，独立 CLI 包通过现有 fresh-profile 常驻启动烟测。

尚未进行 Windows/MatePad 实机账号验收时，发布报告明确保留该限制。
