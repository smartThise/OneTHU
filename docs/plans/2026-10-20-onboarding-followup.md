# 导览落点与模式边界验收（2026-10-20）


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

本轮对齐开屏导览各章节操作按钮的名称与实际跳转落点，同时完整保留三种使用模式下的本地已有内容及完整模式存档。

## 修改

- 完整模式的 11 节导览统一绑定明确的功能入口：白板首页、工作区分栏、暂存箱收发、组织分栏、OneGO! 收藏、插件中心、外观与布局、课程页以及数据与同步；NFC 章节明确引导用户先打开收发面板，再点击接收查看当前设备的硬件支持情况。
- 实用模式导览中的「展开更多功能」现可直接呼出带搜索框的完整功能目录；定向打开 OneGO! 时会自动清空历史搜索词，防止残留筛选条件遮蔽工作区列表。
- 点击「继续导览」返回时自动收起刚才打开的功能练习弹层；从设置页重新播放导览时也会先行清理上次遗留的练习状态。若用户在体验设置页时主动切换了使用模式，返回导览后会自动从新模式的第一课平滑接续。
- 极简与实用模式的接入尾页收起高级 MCP 开关，仅在完整模式尾页展示并读取当前已保存的开关状态；跨模式切换或重放导览时，完整模式下已有的 MCP 配置保持原样。
- 悬浮球介绍文案调整为说明 OH 设置入口位置，移除了与当前实际默认状态不符的「默认关闭」表述；悬浮球的本地存档、默认开关行为与原生启动逻辑均保持不变。
- 为六个新增章节补齐专属示意画面，让工作区、插件、外观等课程各自呈现贴合主题的视觉内容，告别此前重复借用「今日待办」示意图的临时做法。

- `tools/experience-browser-test.mjs`：完整保留模式存档隔离、组织管理、口令分享、实用模式快捷入口持久化以及 390/320 视口排版检查，并将断言中的导览章节标题同步至最新文案。最新一轮全量重跑共 83 条功能断言全部通过、页面零报错，浏览器自然退出（exit 0），`docs/onegui/experience-mode/report.json` 记录为 `passed: true`。
- 浏览器测试夹具已隔离开发服务器热更新，收尾时按序卸载路由拦截、释放请求上下文后再关闭浏览器实例；若发生超时则直接判定失败退出，确保退出码真实反映测试结果。
- 桌面端类型检查与导览静态护栏均已通过；NFC 环节完成了收发面板与设备支持提示验证，真机实体碰一碰留待双机环境测试。

## 后续体验打磨需求（历史登记，本批已完成实现）

用户随后补充反馈：当时版本的导览视觉仍显单薄，希望进一步打磨细腻动效、为三种模式量身定制引导内容，并探索流畅的 3D 与流体视觉表现。本轮聚焦功能落点对齐与模式边界收敛，将视觉体验升级立项为紧随其后的独立打磨批次。

本节保留最初的需求登记记录；后续实际落地与视觉方案演进详见 [三种模式的空间导览与交互演示](2026-10-20-onboarding-motion.md)。最终定稿将主线课程精简为极简模式两课、实用模式三课、完整模式五课，原完整模式其余六个主题收纳进末页「继续探索」（上文提及的 11 课统计对应本轮功能落点阶段）。视觉呈现最终采用真实 Three.js 3D 模型与连续相机运镜，撤去了中途试验过的粒子与霓虹光轨，CSS 立体卡片仅保留作为无 WebGL 环境下的功能降级；最终视觉验收报告见 [验收记录](../onegui/onboarding-motion-2026-10-20/README.md)。

- **极简模式**：以最短路径讲清五个 OneShot 快捷入口、今日待办与即将上课、OH 与全局搜索，轻快演示后即可进入日常使用，界面保持纯粹的极简语境。
- **实用模式**：围绕高频入口、可替换快捷按钮与「更多功能」目录组织情景式引导，让用户亲手完成一次常用操作，再按需展开深入探索。
- **完整模式**：重点围绕自由白板、暂存箱、短口令、NFC 碰一碰与组织协作呈现连贯的空间交互演示，其余进阶主题做轻量收口，避免逐页平铺直叙。
- **视觉与动效候选方向**：模式选择卡片具备轻量 3D 空间层次；演示模型在章节切换间连续形变与运镜；暂存箱开合收纳、口令翻转传递、雷达/NFC 双机靠近、组织名片展开均配有贴合语义的空间动作，让流畅动效自然传达操作因果。
- **实施要求**：全面复用 OneGUI 组件与动效令牌；全程支持跳过、后退、重播并直达真实业务功能；严格适配系统与应用内的「减少动态效果」选项，并在手机视口下逐项核验帧率、触摸热区、文字可读性与遮挡情况。
