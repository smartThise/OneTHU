# 反馈修复：30 项 PDF + Segment 溢出指示条


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

基线：`exp` / `96a0a395`，接手时工作区干净。问题来源为 2026-10-18 用户体验反馈 PDF（共 8 页）及当晚补充说明，逐项修复与验收记录如下。

## 验收清单

括号内的「证据」对应 `tools/feedback-repairs-browser-test.mjs` 的自动化断言项（运行产物归档于 `docs/onegui/feedback-repairs/`）；涉及桌面原生运行时的条目则结合实现位置与单元测试核验。

- [x] 1 横排标签页不可见 —— 根因是底栏 `.ex-bbar` 与顶栏同时 `fixed` 在 `top:0`，底栏层级更高从而遮住了整条标签栏；现拆分为「标签条 44 + 底栏 60」上下两行，桌面端三栏（标签栏、底栏、OneGO）互不遮挡（证据：横标签、OH 和收藏栏互不覆盖）
- [x] 2 白板工具栏图标含义不清 —— 右侧浮动工具从纯图标 `IconBtn` 改为带中文说明的 `Btn`：`组件 / − / 100% / ＋ / 画笔`；手机端同步调整排布，消除按钮加宽后与硬刷新悬浮钮的重叠（证据：白板工具栏按钮带中文标签；手机 390/320 硬刷新钮不压白板工具）
- [x] 3 登录按钮无效 —— `Btn` 默认 `type="button"`，导致表单内的登录按钮点击后未触发表单提交；显式设为 `type="submit"` 后，点击与回车均正常触发 `form.onSubmit`（证据：登录按钮是表单提交钮；登录按钮点击真的提交表单）
- [x] 4 竖排标签栏覆盖 OneGO —— 竖栏模式下使用 `--og-rail-full-width/narrow-width` 为主内容区留出左侧宽度，OneGO 收藏栏从竖栏右边缘起算（证据：完整竖栏不盖 OneGO）
- [x] 5 标签 `+` 应新增首页实例 —— `+` 调用 `openTab('homepage', …, {forceNew:true})`，每个新建实例拥有独立 ID 并在页面刷新后持久保留（证据：+ 新建独立首页标签 / 新首页显示完整画布 / 新首页刷新后保留）
- [x] 6 输入框内侧焦点环闪现 —— 统一由外层壳容器绘制焦点环，原生 `.og-input-el:focus` 的内描边与内阴影全部清零（证据：输入框内层无焦点环）
- [x] 7 OH 对话输入位置不明显 —— 在面板底部常驻渲染输入区（`TextArea` + 发送按钮），并与底部胶囊共享同一份草稿状态（证据：OH 面板内有可见输入框；OH 面板和胶囊共享同一草稿）
- [x] 8 首页预设布局混乱（保留用户自定义布局）—— 在保留存量用户布局的前提下，新增「设置 → 外观与布局 → 恢复默认首页布局」一键复位入口（清空自定义排列、折叠与隐藏记录），恢复为 `homeStarterItems()` 标准七件套（证据：设置提供「恢复默认首页布局」；桌面首页截图）
- [x] 9 卡片点击区域不完整 —— 将 `Card` 的全铺点击判定扩展到 `stat-click / course-card`，让入口按钮铺满整张卡片，点击右侧与下侧留白区域同样响应跳转（证据：卡片入口按钮撑满整卡；卡片右边与下边的空白区也在点击范围内）
- [x] 10 Segment 选中文字消失 / 选中胶囊缺失 —— `Segment` 选中滑块改用显式 `left/width` 定位（替代原先会导致圆角变形的 `scaleX`），选中态字色绑定 `--og-content-1`（证据：Segment 胶囊指示器可见且按选中项落位；选中文字与胶囊底色有清晰反差）
- [x] 11 暂存箱应浮动，不挤占内容高度 —— 桌面端暂存箱锚点改为 `position:fixed` 浮层，主内容区顶部直接从三栏底边起算（140px），释放整行纵向空间（证据：暂存箱锚点是浮层；内容从栏底开始不被再挤一行）
- [x] 12 侧栏底部按钮悬停后位置改变 —— 侧栏底部动作区固定 `flex:none`，鼠标悬停时保持原位稳定（证据：侧栏底部按钮悬停后原位不动）
- [x] 13 侧栏完整 / 窄模式图标大小和横向位置不一致 —— 图标槽固定为 `--og-ctl-h-lg` 居中对齐，展开与收起状态下几何位置完全一致（证据：侧栏图标展开前后尺寸和位置一致）
- [x] 14 名片删除确认被详情遮挡 —— 将确认弹窗通过 Portal 挂载至 `body` 并提升层级至 `--og-z-confirm`（证据：名片删除确认显示；删除确认在名片详情之上；取消删除保留名片详情）
- [x] 15 页标题与内容间距不足 —— `.og-pagehead` 统一设置底部间距 `margin-bottom: --og-space-6`（证据：页标题与下方内容有统一间距 24px）
- [x] 16 按钮中文下沿被截断 —— 调高 OG 按钮的 `line-height` 使其大于 `font-size`，完整呈现汉字上下笔画（如“返”的走之底、“载”的下半部）（证据：按钮中文上下沿有足够行高）
- [x] 17 折叠列表缺少收起动画 —— `AccordionItem` 保持子内容常驻挂载，改用 `grid-template-rows: 1fr ↔ 0fr` 实现展开与收起双向平滑过渡（证据：折叠展开有过渡 / 折叠收起也有过渡 / 收起后高度归零）
- [x] 18 浮层玻璃只透明、不模糊 —— 遮罩入场动画改为 `fill-mode: backwards`（避免 `forwards` 残留永久 backdrop root 导致 `backdrop-filter` 失效），玻璃皮肤下遮罩与面板均正常渲染 `blur(20px)`（证据：玻璃皮肤下遮罩与面板都有模糊；遮罩入场动画不留下永久 backdrop root）
- [x] 19 首页组件多余滚动条 —— 组件卡体改为**静默滚动**：保留滚动能力的同时隐藏滚动条轨道（`scrollbar-width:none` 与 `::-webkit-scrollbar{width:0}`），消除时钟等卡片因 2px 微小温差露出的滚动条（证据：首页组件卡静默滚动）
- [x] 20 胶囊按钮样式不统一 —— 行内状态标签 `.task-tag` 与 `.chip` 对齐相同的 24px 高度、圆角与内边距，并直接采用固定的 4pt 间距令牌以在 touch 密度下维持精致尺寸（证据：状态胶囊与 chip 同高同圆角 24/24）
- [x] 21 页面字号层级失衡 —— 子页页头标题从 `display` 档收敛至 `title` 档（24px），让作业详情等页面的标题与正文比例更协调（证据：页头标题用 title 档 24px）
- [x] 22 OnePage 右键同时打开菜单和添加抽屉 —— 在画布卡片 `onContextMenu` 中停止事件冒泡，确保右键仅唤起当前上下文菜单（证据：右键不会同时弹出菜单与添加抽屉）
- [x] 23 OnePage 壁纸变化前景字色不更新 —— 亮度采样在 `.explorer-shell` 处收口，避免外层画布底色冲淡壁纸采样结果；切换深色壁纸后前景标题自动转为亮色（证据：深色壁纸给壳层打上 data-wallpaper-lum=dark；深色壁纸上前景标题转亮）
- [x] 24 拖动期间画布边界不随动，组件被裁切 —— 画布容器尺寸纳入**正在拖动组件的实时矩形边界**动态扩展，拖向边缘时画布实时跟随延展（实测 1116→1480px）（证据：拖动改尺寸时画布边界实时跟随）
- [x] 25 组件背景材质不统一 —— 表面材质统一集中在最外层条目（`.free-item`），内部嵌套的 `wg-card/og-card/home-card` 设为全透明且无描边、无阴影（证据：组件卡内层不再叠第二层底 6/6）
- [x] 26 清小搭气泡没有内边距 —— 为 `.og-surface` 补齐 `padding: var(--og-c-surface-pad)`，恢复气泡与卡片的 `Surface pad="lg"` 内边距表现（证据：Surface 内边距实际应用）
- [x] 27 清小搭技能广场无交互反馈，背景异常 —— **交互反馈已补齐**：点击技能行可打开包含作者、分类与下载量的详情弹窗；「背景统一样式」与「技能广场接入 OH 技能体系」涉及完整的智能体技能注册与管理改造，按 2026-10-18 排期结论留待后续专项推进
- [x] 28 标签过多把侧栏功能按钮挤出 —— 竖栏内部标签列表设为独立滚动区域，底部功能按钮固定 `flex:none`（打开 30 个标签时底部按钮依然稳居屏内）（证据：30 个标签时底部动作仍在屏内；30 标签截图 vertical-rail.png）
- [x] 29 我的组织出现在每个设置页 —— 将「我的组织」从通用设置分区中移出，统一归口至「我的」与通讯录页面（证据：设置不再重复显示我的组织）
- [x] 30 OH 免费模型显示可用却报缺 API Key —— 两处联动修复：① 设置页按「清华免费档 / 自有密钥」准确展示当前配置状态；② 宿主在调用 `callRust(onethu.harness.run)` 前先执行 `preflightMadModel()`，若未能获取免费档令牌则直接提示具体原因（需连接校园网/VPN 或改配自有密钥），并在服务端作废旧令牌时自动重签（证据：默认走清华免费档语义；免费档异常时提示具体网络或认证原因）。校园网与统一身份认证的在线联调另行在实机环境下验证
- [x] 31 长 Segment 底部恢复可拖动位置指示条 —— 同时兼容新版 `SegmentScrollIndicator` 与旧版 `SegmentedOverflow`：仅在选项横向溢出时显示指示条，支持鼠标拖拽滑块及键盘 `←/→/Home/End` 导航（证据：.og-segment-scroll / .seg-indi 溢出指示条可见且真实鼠标拖动滚动选项）

## 本轮一并修复的基线护栏问题（96a0a395 既有遗留）

- `docs-prose-lint`：将 `docs/onegui/navigation-rebuild/README.md` 中的口语化表达统一改写为规范书面陈述。
- `dynamic-flow-test` / `dynamic-color-test` / `theme-system-test`：修复 OneGUI 重构后的主题联动回归——此前 `deactivateTheme/activateTheme` 会连带清除 `followSystem`，导致切换动态取色开关后丢失「跟随昼夜」偏好。现拆分为 `detachAppliedTheme()`（仅卸下当前主题变量，保留昼夜调度）与 `setFallbackTheme()`（仅切换降级视觉主题，保留用户原选择），并在开启取色偏好时保持 `applyActive()` 静默；测试断言同步对齐新接口，继续严格校验动态取色接管与基础令牌恢复。
- `button-variants-test`：FAB 悬浮钮已并入毛玻璃样式配方，将测试断言更新为校验底色走设计令牌；`.slot-cell.picked` 的选中态强调边改为等效的 `box-shadow`，与键盘焦点环清晰区分。
- 基线 `96a0a395` 上另有 **16 个**面向旧版 DOM 类名编写的护栏脚本待迁移：`card-layers`、`empty-state`、`theme-ia`、`density`、`controls`、`list-row`、`nav-shell`、`xiaoda-entries`、`explorer-canvas`、`tabstrip-layout`、`modal-shell`、`theme-picker-layout`、`settings-ia`、`help-coach`、`onboarding-v3`、`widget-coverage`。这些脚本仍在匹配 OneGUI 重构前已退役的类名与文件（如 `.plg-tab`、`.empty-icon`、`.cloud-row`、`Today.tsx`），已单独排期统一更新。

## 处理原则

延续当前 OneGUI 设计体系，从共享基础原语与布局根因着手解决问题，完整保留用户本地数据与既有测试标准。浏览器回归运行在隔离数据目录中，覆盖桌面与手机视口、深浅色主题以及真实点击和指针拖动；模型调用链路通过本地夹具验证配置传递与错误分流，零额度消耗，在线校园网服务则单列实机联调说明。
