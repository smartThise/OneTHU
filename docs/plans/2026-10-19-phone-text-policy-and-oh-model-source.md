# 手机文字/排布统一策略 + 设置收口 + OH 模型源（2026-10-19 深夜）


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

本轮集中处理一批界面排布与设置收口反馈（用户原话摘录）：
- 「手机版很多文字省略号回来了，不能统一解决一下吗」；
- 「很多文字在左边挤成一堆，右边单独放一个组件」；
- 「设置里面应该把模式选择默认收起来，不要一直一大块挡着人」；
- 「一个电脑，一个手机，这两个按钮排布你不觉得看起来就很乱吗」；
- 「设置里的 segment 太不直观」（指 账号/通知与提醒/外观与布局/数据与下载… 那排栏目）；
- 429 原文气泡要删掉，改成「一键续签 / 设置自己的 API」；
- 「胶囊自带接管所有这个地方的文字输入，删了 OH 自己的输入框」；
- 设置里也要能一键续签，极简/实用可选 MadModel 或自己的 API；
- 完整模式不在通用设置里放简化配置：「删了。在高级设置里调」。

## 手机文字/排布统一策略

新增 `packages/gui/src/styles/phone.css`（置于 `gui.css` 末尾引入，确保优先级高于组件默认样式）：

- `.og-row`：支持自动换行；`.og-row-main` 至少占行宽 55%，右侧控件空间不足时整块换到下一行；标题与副标题最多显示两行，告别单行截断省略，右侧控件保持右对齐。
- `.og-settings-row`：主列宽度从 55% 起步，右侧值与控件支持换行并右对齐。
- `.og-pagehead-main`：手机端独占整行，操作按钮换到下一行；包含标题的 `.og-inline:has(h1/h2/标题)` 改为纵向 grid 排布。
- `.og-kv`：手机端改为「标签在上、值在下」的左对齐纵向排布，避免组织概况和名片信息把字段值挤到右侧边缘。

旧版样式同步在 `apps/desktop/src/styles/global.css` 末尾追加手机端统一规则：
- 覆盖早期手机样式中 `.row { flex-wrap: nowrap !important }` 的强制单行限制；
- 将 `.row-title/.row-sub` 等 20 余个旧版文本类统一改为最多两行显示或自然换行；
- 卡片头、区块头、设置行等「左标题 + 右操作」结构支持空间不足时自动折行。

浏览器回归测试 `tools/phone-layout-browser-test.mjs` 覆盖 390 与 320 视口下的通讯录、云盘、暂存箱和组织页面，验证无横向溢出、内容文字无单行省略、键值对单列展示、成员行文字占宽不少于半行以及名片按钮等宽对齐。

## 设置页收口

- 「使用模式」默认收起为单行摘要（显示当前模式与切换按钮），选择完成后自动收起。
- 设置栏目导航（账号/通知与提醒/桌面小组件/外观与布局/数据与下载/…）在手机端改为下拉选择器，桌面端保留左侧栏目列表，省去横向滑动查找栏目的麻烦。
- 名片面板的 8 个操作按钮改为等宽网格（桌面端每排 4 列、手机端每排 2 列），按钮文字允许自然换行，完整展示标签内容。

## OH：429 动作卡 + 删除面板输入框

- 对话遇到 429 或额度限制错误时，直接展示可操作的动作卡「免费额度被限流了（429）· 一键续签 / 设置自己的 API」，替代原先的原始报错气泡。点击续签会调用 `ensureMadModelToken(true)`，点击设置 API 则打开 OH 页面并定位到「模型 / MCP / 日志」高级配置。
- 移除 OH 面板内的第二个文本输入框，文字输入统一收口到底栏胶囊 `ohx-input`，面板底部仅保留附件入口。

## 小 OH · 模型源卡片（设置通用）

新增 `components/OhModelSourceCard.tsx` 组件，按使用模式分流配置入口：
- 按 2026-10-19 最终确认的交互方案，该卡片仅在**极简/实用模式**的设置页中展示；
- 直观展示当前模型源与模型名称，选用学校 MadModel 免费档时提供有效期展示与「一键续签」按钮；
- 支持在免费档与自定义 API 之间直接切换，地址、Key 和模型名称可在下方「小 OH · 自己的 API」区域填写；
- **完整模式**的续签、模型源切换与 Key 配置统一集中在 OH → 高级配置中调节（高级配置新增带「一键续签」的「免费额度（MadModel）」行，429 动作卡的「设置自己的 API」也会直接跳转 `goOhRow("模型 / MCP / 日志", "advanced")`）；
- 后台自动续签机制保持常驻：`startMadModelPump()` 随插件 loader 启动，每 10 分钟巡检一次，在到期前约 1 小时（`RENEW_BEFORE_EXP_MS`）自动续期，设置页按钮作为手动兜底入口。

## 手机白板：自由摆放（仅完整模式）

针对用户反馈「手机上也要允许白板拖动和改变大小，而不是现在这个样子只能上下调整（仅限完整模式）」，补充手机端白板画布能力：

- 手机竖屏默认维持**阅读顺序**（单列堆叠），兼顾日常单手浏览体验；
- 完整模式白板顶部新增「自由摆放 / 阅读顺序」切换开关（状态持久化至 `onethu.board.phoneCanvas.v1`）。切至自由摆放后进入真实画布模式（世界坐标 + 缩放），支持直接拖动卡片、点选后拉动四角或边缘把手调整尺寸，首次进入自动缩放到 200% 并提示「拖动卡片，点选后拉角点调大小」；
- 极简与实用模式本身无白板视图，该开关仅在完整模式下呈现；
- 样式层面通过 `.freeboard-wrap.phone-canvas .free-item { touch-action: none }` 防止垂直拖拽与页面滚动冲突，切回阅读顺序后恢复 `pan-y` 正常纵向滚动。
- 新增 `tools/phone-board-browser-test.mjs` 共 14 条回归用例，覆盖默认阅读顺序、切换自由摆放、拖动移位、拉动把手调尺寸、切回阅读顺序及极简/实用模式无白板验证。留存截图：`phone-board-stack.png`、`phone-board-free.png`。
