# i18n 工程接入与翻译交接状态


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

2026-10-20，`exp` 分支；本轮直接在当前最新业务代码上完成 i18n 工程化迁移，跳过了 PR 57 中已过时的历史业务改动。

## 已落地

- 支持语言偏好持久化、多窗口实时同步、`document.lang` 自动更新以及三种使用模式下的语言切换；组件通过订阅语言状态热更新文案，无需卸载重挂整个应用。
- OneGUI 内置独立语言 Provider，表单、确认弹窗与 Toast 均支持消息描述符，已打开的弹层在切换语言时可即时刷新文案并保留用户已输入的内容。
- 支持具名参数插值、可信 React 节点槽位、显式复数分支以及基于 `Intl` 的日期与数字格式化；模块级静态注册的展示项改为读取时动态解析。
- 直接从当前界面与状态层提取全量词典，完整输出源文案、代码调用位置、插值参数、分批文件及配套术语表；种子生成工具仅在中文源文完全一致时复用历史候选译文。
- 学校接口协议字段、权限标识、稳定路由键、日历事件身份与用户本地存档名均保持原始值，仅对界面展示标签做独立翻译；同步修复了迁移审查发现的 THOS 状态判断、洗衣机键值、设置项定位及课程行 Atom 身份耦合问题。
- 词典文件统一采用静态 AST 解析校验，全程零代码执行；遇到缺键、插值参数不匹配、重复属性、源文版本漂移、批次未填完、跨批次改动或触碰业务源码时均会直接拦截报错。
- Vite 构建自动发现并注册新增语言文件，desktop 生产构建前强制执行工程词典完整性检查。
- Android 桌面小组件快照同步携带当前语言标识与 62 条显示模板，后台刷新倒计时时沿用快照语种；应用内切换语言会立即推送新快照，并通过代号校验防止在途旧异步任务覆盖新快照。所有小组件文案统一收敛在同一份主词典中维护。

## 工程命令

```sh
pnpm i18n:check
pnpm test:i18n
pnpm i18n:handoff
pnpm --filter @onethu/desktop build
```

翻译模型只需填写目标语言字段并运行校验命令，提取与批次重生成统一由工程侧维护；批次校验须附带工程基线参数执行，具体用法详见翻译指南。

## 后续翻译与验收范围

当前已完成 i18n 工程底座接入，英文词条仍有待翻译填充（未填项在运行期平滑回退至中文）。正式发布前需运行 `--locale en-US --complete` 确认全量词条覆盖，并完成英文译文质量审校及长文案下的真实界面排版验收。后续新增其他语种时，由工程侧预置纯数据词典文件后即可按同一流程填充。

现有学校官方英文页面样本涵盖网络学堂英文首页与 Info 英文门户，选课内页与作业详情的真实英文样本留待后续补充。本轮已完成双语匿名解析、真实 `DOMParser` 解析与异常兜底验证，全程保持学校端原有语言设置不变，也未发起真实选课、退课或作业提交；官方课程英文名仅用于界面展示，本地存档与导航路由身份保持稳定。

本轮界面验证在本地 Chromium 与 WebKit 中覆盖了三种使用模式及桌面/手机视口；Windows WebView2、Android/iOS 真机表现以及学校双账号联调留待对应设备环境补齐。系统日历写入、系统通知、IM 自动回复、界面实拍截图以及用户或学校产生的原始内容各自维持原有语种，独立于应用 UI 语言切换。

历史 PR 57 的遗留问题与原迁移背景可参阅 [PR 57 深审](../reviews/2026-10-20-pr57-i18n-handoff.md)。正式前端资源热更新已按用户后续安排移出本轮范围；既有整包更新链路的加固详情见 [更新审查](../reviews/2026-10-20-updater-audit.md)。
