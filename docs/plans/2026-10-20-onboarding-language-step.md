# 导览第 0 步：语言选择


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

开屏导览新增第 0 步语言选择：先以固定的中英双语并列引导用户选定界面语言，随后再进入使用模式挑选及对应模式的章节导览。语言候选项动态读取 `availableLocales()`，仅列出已完成词典注册的语种，并直接用各词典自身的语言名称呈现。用户点选后立即写入全局语言偏好并实时刷新界面文案，全程无需整页刷新，完整保留当前使用模式与本地已有数据；无论是点击后退还是从设置页重放导览，均可顺利回到第 0 步重新选择。

界面实现直接复用现有的 OneGUI `Modal`、`Radio` 组件与导览布局配方。第 0 步省去顶部演示舞台，语言列表支持纵向滚动，底部「继续」按钮固定常驻；各章节标题与模式简介已全部补齐词典接入，后续新增语种只需注册对应词典即可自动出现在候选列表中。

验收覆盖：首次冷启动打开、设置页重放、步骤后退、切换语言后分别进入极简/实用/完整三种模式；语言偏好持久化与页面刷新恢复；通过隔离浏览器夹具挂载第三语种词典验证动态扩展能力；320px 窄屏手机与桌面视口排版、键盘方向键选择与焦点管理；以及 i18n 批次重生成、全量词典校验、TypeScript 类型检查与既有导览回归套件。
