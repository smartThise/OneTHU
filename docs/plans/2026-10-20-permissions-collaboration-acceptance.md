# 权限、组织协作与交互验收


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

本轮基于 `exp` / `8d24630f` 推进，按用户授权完成五项核心安全与交互审计整改，并预留好线上双账号联调入口（当前本地尚无第二个校园测试账号，也暂未连接 Android 实机）。

## 设计决定

1. 云盘资料库权限统一以清华云盘服务端实际生效结果为准。授权、降权、移除成员及更换绑定邮箱均严格执行「读取现状 → 提交修改 → 回读核实」三步校验，确认服务端 ACL 真实更新后才标记完成；远端待办日志持久化记录未完成步骤以支持失败重试，且始终遵循先撤权、后增权的安全顺序。
2. 组织协作以私有 GitLab 群组成员列表作为权威身份源，并通过专属私有仓库存储共享状态。管理配置与协作内容分别隔离在不同的受保护分支：普通成员仅读取管理配置，具备编辑权限的成员可维护项目与公告；文件更新全部附带提交版本校验，遇到并发冲突时妥善保留本地已编辑内容。存量本地组织通过显式初始化流程升级为多人协作组织。
3. 清华云盘当前运行版本为 Seafile 11.0.21，暂未开放新版公开链接按指定账号限流的接口。为此私密分享采用端到端 `AES-256-GCM` 加密方案：公开短链接内仅存放密文载荷，每条分享生成的独立随机密钥单独保存在私有密钥资料库中，依托云盘原生的指定账号共享权限向接收人精准授钥，随附文件同样全程加密。调整接收人范围时会自动轮换新密钥与新口令并撤销旧链接，仅修改显示名称则可平滑复用原口令；撤权前已被接收方读取到本地的内容受限于离线物理特性无法远程擦除，后续新增或更新内容则会立即对被撤权方不可读。
4. 开屏导览每一课的操作按钮均直接打开对应的真实业务功能，并提供清晰的一键返回导览入口；实用模式导览严格贴合实用模式边界，重播导览时完整保留用户已有的偏好配置。
5. OneGUI 全面采用语义令牌与共享基础组件收口样式，严守既有 CSS 行数与对比度基线；手机端验收涵盖真实视口坐标触摸、拖拽、双指/把手缩放、滚动、遮挡排查及实拍截图人工复核。

采用独立密钥资料库托管私密分享密钥虽会增加少量轻量级配置文件开销，但彻底省去了自建中转后端，并将接收人身份核验牢牢放在云盘服务端完成。组织内容依托 GitLab 仓库文件存储，配套提交版本冲突提示与定时拉取刷新，契合团队项目与公告的异步协作场景。

服务端接口依据：[Seafile 分享 API](https://cloud.seafile.com/published/web-api/v2.1/share.md)、[11.0.21 分享链接实现](https://github.com/haiwen/seahub/blob/v11.0.21-pro/seahub/api2/endpoints/share_links.py)（线上实际部署版本与接口能力已通过只读服务端探测核实）。

暂存箱浏览器回归在初期曾出现“50 项断言全过但浏览器关闭阶段超时”的现象：排查定位到 macOS 下测试 Chrome 拉起的后台 `GoogleUpdater` 子进程继承了 stderr 文件描述符，导致 Playwright 一直等待进程输出流闭合。为该隔离测试启动参数补充 `--disable-updater-scheduler` 后，顺序重跑 50 项断言全部通过，Chrome 进程自然退出并干净回收临时目录（全程无需强杀进程或改动宿主机 Chrome 更新配置，成功提示也同步调整至资源清理完毕后输出）。

## 保留的外部联调

遵照当前单账号开发安排，以下依赖第二真实账号或物理移动设备的联调入口已就绪，待外部条件具备时直接执行：

- 真实清华云盘双账号读写授权、降权与撤销联调：`cargo test --lib seafile::tests::live_two_account_permissions -- --ignored --nocapture`（所需环境变量配置详见私密分享报告）。
- 真实清华 GitLab 实例写接口与双账号互访联调：`node tools/org-collaboration-live.mjs --run-isolated`，自动创建独立测试群组并在收尾时清理，支持注入 `GITLAB_TOKEN` / `GITLAB_SECOND_TOKEN` 且全程脱敏不打印令牌。
- Android 物理真机、系统输入法软键盘、原生文件选择器与 NFC 硬件交互：待连接 Android 实机后，在移动 Chrome 可信触摸回归的基础上补齐原生系统链路验证。

历史版本生成的明文受限分享链接在再次发起分享或点击「升级并复制」时会自动迁移至端到端加密方案；尚未触发升级的旧链接可由发送方主动撤销或一键升级。
