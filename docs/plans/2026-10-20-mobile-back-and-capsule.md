# 0.11 手机胶囊与返回导航修复


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

按用户安排先暂停 APK 打包，优先修复手机端底栏 OH 胶囊占位文字偏左以及 Android 系统返回键直接退出应用的问题。

## 设计与根因

- 版本号统一升至 `0.11.0`，关于页移除 beta 标识（对应提交 `f4615273`）；暂停期间未生成或交付新安装包。
- 底栏 OH 胶囊在常态下即便左侧没有收藏星标，原有的平衡槽仍会占据宽度，叠加 OneGUI workbench 配方强制靠左对齐，导致手机上占位提示偏左。本次在统一配方中收口手机端样式：移除空置平衡槽并将提示组居中，右侧出现星标或未读徽标时留出对称避让空间，极窄屏幕下允许提示文字自然省略；激活输入与语音收音状态维持原有交互布局。
- 自从 Explorer 取代旧版页面路由后，页面切换尚未接入 `navStack`，栈内仅剩零星浮层消费者：既缺少页面级浏览历史，停留在根节点时也未必挂载了 Android `onBackButtonPress` 监听。
- 返回导航直接复用既有的 Tauri AppPlugin 返回键 Channel 与 `mobile_exit` 命令，由应用自有导航栈统一管理回退逻辑，无需依赖 WebView `canGoBack`、`pushState` 或修改 UA。监听注册处新增并发门闩，防止首帧同时挂载多个浮层或 React StrictMode 双重执行引发重复监听。

## 返回规则

1. 优先关闭最近打开的顶层浮层（含设置、OH 面板、标签抽屉、OneGO、命令面板、大图预览以及已打开的表单或详情弹层）。
2. 无浮层时回退至当前使用模式下的上一处导航位置，完整保留课程与作业参数及标签身份，同时维持现有标签列表不变（既不误删活动标签，也不重新唤醒已关闭标签）。
3. 极简、实用、完整三种模式各自维护独立的有界会话历史，并始终以首页作为栈底锚点；即使冷启动直接恢复到非首页视图，按返回键也能顺利退回首页。
4. 仅当已处于当前模式首页且无任何打开的浮层时，才调用 `mobile_exit` 交由系统退出应用。

大图预览原有的同 URL 历史记录也已统一迁入 overlay 栈管理，避免返回键被 Tauri 层接管后出现大图无法按返回关闭的情况。

## 验证

运行 `tools/mobile-shell-back-browser-test.mjs`，覆盖 320、390、430 三档手机视口宽度、三种使用模式以及页面与浮层多级回退；同步执行既有的 nav-stack/mobile-nav 单测、类型检查、CSS 结构校验与 OneGUI 守卫。浏览器环境已完成真实应用状态流转与返回回调验证；Android 物理设备的系统手势与三键导航留待恢复 APK 打包后上机复核。

## 验收结果

- 手机端真实应用浏览器验收 118 项全部通过，覆盖三档视口 × 三种模式、课程详情参数保留、已关闭标签跳过、模式切换历史隔离，并通过 API 适配器模拟 Android 返回键回调（确认仅在首页根节点触发 `mobile_exit`，且全局监听器仅注册一次）。
- 人工核验 390 宽度手机实拍截图，确认常态下 OH 图标与占位提示组已视觉居中；截图归档于外置构建盘 `/Volumes/OneTHUBuild/artifacts/mobile-shell-review/`。
- 导航栈单测 15 项、Android 退出行为单测 4 项、导览导航 21 项、桌面类型检查、CSS 结构、OneGUI 守卫及 7343 条中英文词典校验全部通过。
- 首次进入生活或预约页面时会自动补全默认子栏目参数；此类从 `null` 到默认值的初始化更新已合并至当前历史栈顶，避免用户按返回键时多出一次原地停留的空退。
- 当前暂未连接 Android 实机且按约保持暂停 APK 构建，真机侧滑手势与导航栏三键表现待后续连机补验。
