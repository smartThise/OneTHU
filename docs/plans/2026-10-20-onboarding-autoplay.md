# 导览自动播放、手机屏幕与连续退场


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

2026-10-20 · `exp` · 起点 `afb24054`

根据用户反馈移除手动点击模拟、细化手机屏幕细节，并修复切换下一步时旧模型在画面边缘滞留后突兀消失的问题；设备屏幕贴图统一采用实际运行的应用页面截图，弃用另行手绘的近似示意界面。

## 实施

- 进入导览章节后舞台自动按「展开 → 停留 → 收回」节奏循环播放；待三维模型运动到位后才启动停留计时，切换章节时立即清理上一课的计时器。界面仅保留暂停开关与直达真实功能的入口按钮；遇到手动暂停、滚出视口或切到后台时自动冻结计时，开启「减少动态效果」时直接展示清晰稳定的静态终态。
- 手机与平板屏幕统一贴入实际运行的 OneTHU 页面截图：所有截图均由生产组件与真实样式渲染生成，仅通过本地隔离数据夹具注入示例课程与条目，原汁原味保留完整截图比例，不额外补画导航栏、按钮或系统状态栏，并确保机身边框与镜头开孔避开应用交互控件。
- 三种模式的首页、课表、实用模式功能目录与快捷入口替换、暂存箱收发、组织协作及选修探索页面均配有可复现的自动截图脚本与来源清单；同步移除了设备旁虚构的装饰伴随卡片，白板平板模型也直接展示真实白板首页。
- 按后续视觉反馈进一步收窄手机边框，移除机身背面的 OneTHU 标志与屏幕底部的实体横条；单手机演示章节放大舞台占比并收紧相机取景，NFC 碰一碰章节则保持双机完整同框。
- 在内存层缓存解码后的 CPU 图像，由每个三维模型实例独立管理各自的 GPU 纹理并在退场销毁后及时释放；资源全部就绪后再挂载三维场景，遇到不支持 WebGL 的环境则复用同一套真实截图做 CSS 降级展示。
- 模型退场路线根据当前相机视锥动态计算出口坐标，在连续位移中平滑渐隐；快速连续切课时支持从当前姿态反向丝滑衔接，并在节点卸载前彻底消除边缘残影。
- 跨使用模式快速切回同一章节时，根据模型实例记录的模式标识实时刷新屏幕截图纹理，确保复用正在退场的实例时也能准确呈现当前模式的界面。

## 验收

覆盖自动循环播放、暂停/后台隐藏/减少动态效果响应、三种模式真实功能直达与返回导览。在桌面视口与 390 手机视口下录制自动播放及快速连续切课视频，人工逐帧核查屏幕贴图清晰度与边缘退场过渡，并在 320 矮窄屏下补验排版。同步通过类型检查、OneGUI guard、导览专项测试与生产构建；精选关键截图、录屏短片与验收摘要归档于 `docs/onegui/onboarding-autoplay-2026-10-20/`。

截图采集脚本包括 `tools/capture-tour-real-ui.mjs`、`tools/capture-tour-real-ui-workbench.mjs` 与 `tools/capture-tour-real-ui-extras.mjs`，对应的截图来源清单与哈希记录保存在 `apps/desktop/src/assets/tour/real-ui/`。其中 NFC 章节采用真实的口令收发界面直观演示传递流程，硬件可用性维持设备实际状态；全部截图内容均取自独立测试夹具，与个人真实账号数据完全隔离。
