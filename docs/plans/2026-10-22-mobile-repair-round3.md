**Tech Stack:** React / TypeScript / OneGUI / Tauri / Playwright。

### Task 2: 手机白板编辑优化

- 调整 `components/FreeBoard.tsx`、`state/freeBoard.ts` 与 `packages/gui/src/recipes/workbench.css`。
- 移除编辑入口按钮的多余双层边框；进入编辑态时默认保持当前竖屏阅读比例，将自由画布缩放拆分为显式独立开关；软键盘弹出压缩视口高度时锁定原有横竖屏朝向判定。
- 新增“撤销上一步”与带二次确认的“恢复默认布局”：撤销栈按白板与朝向独立维护，兼容内容高度自动拟合与跨窗口写入，且恢复默认操作本身同样支持一键撤销。
- 在首页与 OnePage 白板上逐一验证拖动、调尺寸、删除、添加组件、文字块编辑、套用模板、恢复默认、系统返回键、软键盘弹出及横竖屏切换。

### Task 3: 悬浮入口打磨

- `onethu-overlay` Android 原生悬浮窗：将手机端收起按钮升级为高对比度样式，配齐清晰的图标与文字标识。
- `state/vaultAnchor.ts`、`components/vault/useVaultAnchor.ts` 与 `VaultDropTarget.tsx`：支持手机端将暂存箱入口拖至屏幕左右边缘吸附并半收起隐藏，轻点露出的把手即可唤回；面板展开或长按拖入传输时自动完整探出确保精准可达。
- 完整保留自由拖动停靠、单击打开管理与长按内容传输，专项测试贴边点击与再拖动、屏幕旋转映射、安全区与底部导航栏自动避让。

### Task 4: 可选导航布局与导览集成

- 新增设备级导航偏好存储与可复用的布局选择器组件，挂载于设置页“外观与布局”分区。
- 提供左上角菜单按钮唤出纵向功能浮层的导航形态（替代底部常驻 OneShot）：极简模式展示核心五项入口，完整模式与实用模式展示全部一级功能区，完整保留各模式原有的权限边界、OH 胶囊与全局搜索。极简模式导览跳过布局分叉以保持轻量，后续仍可在设置中自由切换。
- 新增 `MobileFeatureNavigation.tsx`，直接复用 `0.10` 经典一级功能区图标与译名；收起 OneShot 后正文区自动铺满全宽，展开纵向功能浮层时以叠层呈现而不挤压下方页面排版。
- 在 `components/OnboardingTour.tsx` 中，当手机端用户选定完整模式或实用模式后顺滑衔接两种导航布局的可视化对比选择页；桌面端与极简模式继续走原有导览动线。
- 全部新增文案同步录入 `zh-CN/en-US` 词典与 `static-label seed`，并通过完整 `i18n` 校验。
