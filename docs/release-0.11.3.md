# 0.11.3 登录与更新修复


[中文](release-0.11.3.md) · [English](en/release-0.11.3.md)

OneTHU 0.11.3 · Revolution 覆盖 macOS、Windows 与 Android 三端，重点优化了登录会话恢复、设备身份一致性，并支持在登录界面直接检查和安装更新。现有正式版支持直接覆盖升级，本机数据与设置完整保留。

## 登录界面也能更新

打开应用后，即使尚未完成学校账号登录，登录界面也能直接展示新版本公告；点击「前往更新」即可在独立弹窗中查看安装包信息、跟踪下载进度并确认安装。登录页与二次验证页同时保留「检查更新」入口。

极简、实用与完整模式及中英文界面均支持这一能力。自动更新提醒会主动避开正在输入账号密码或验证码的时刻；用户手动检查更新后，页面中已填写的内容也会原样保留。公告正文支持独立滚动，提醒可选择延后 1 小时、1 天或 7 天。

## 学校服务异常时的恢复

会话检查现将凭据失效与网关过渡页、接口限流、服务端临时异常及网络波动区分处理：已保存账号遇到学校服务短暂波动时会保留本地缓存视图，确认失登后才切入登录流程；探测超时后继续跟踪原请求，避免发起并行的重复密码登录。

若登录准备阶段遇到临时网关页面，界面会给出清晰的稍后重试提示，待学校服务恢复后即可重新登录。错误诊断摘要会记录问题分类与所处阶段，并自动略去密码、验证码、Cookie 与网页正文。

## 设备身份和账号归属

同一客户端实例在并发调用、页面刷新与本机存储恢复期间始终保持一致的设备指纹。同账号重新登录时优先复用已知会话；切换账号、归属待确认或主动退出登录时严格隔离上下文。学校「本次统一登录」选项改为显式勾选，二次验证环节的信任设备勾选项继续保留。

此次改进减少了因重复恢复会话和设备指纹变化带来的额外认证请求。学校已有的信任设备记录由统一认证系统维护；若设备数量达到上限，可前往学校官方管理页面清理。

## 安装包

Android 版沿用正式签名与原版 Logo，versionCode 为 11012。GitHub Releases 与清华云盘镜像同步提供各系统安装包及 SHA-256 校验信息。
