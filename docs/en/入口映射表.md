# Entry map (0.11)


[中文](../入口映射表.md) · English

| Entry | Minimal / Practical | Full |
|---|---|---|
| OH capsule | Search, custom API key, WeChat/Feishu | Search, OH, and authorized tools |
| OneShot | Study, Reservations, Life, Information, Schedule | Same defaults, customizable |
| Home | Today’s tasks and classes; Practical adds service directory | Customizable freeform whiteboard |
| Top area | Current page header and mode settings | Tabs and My, with OneGO below the capsule |
| My | Settings for the active mode | Name card, appearance, sync, plugins, and OH |
| Sharing | Paused while in compact modes (available in Full mode) | Staging box, short codes, NFC, cards, and organizations |

Current navigation routes live in the explorer components and `onboardingNavigation.ts`, superseding the five-tab bar (Today / Tasks / Services / Favorites / My) used in 0.10 and earlier releases.
