## Hold, move, release

Press and hold any supported item until it lifts under your finger or cursor, drag it onto the highlighted staging-box button, and release to save it. Tap the floating button at any time to open the staging box and view your saved items, or drag the button itself to park it anywhere on screen.

![Actual drag with fictional data](../assets/0.11/en-US/vault-drag.gif)

Items with built-in drag adapters can be collected directly into the staging box, including whiteboard widgets, tabs and workspaces, OneGO shortcuts, search results, Web Learning assignments, notices, files, and attachments, schedule events, name cards, emails, cloud files and folders, campus news, GitLab projects, and integrated theme, wallpaper, plugin, and settings entries. Remote files are cached locally before staging when needed, and on desktop you can also capture selected text with its dedicated keyboard shortcut.

## Short codes and NFC

From the unified staging and share menu, you can generate an online short code to send staged items to another user. Entering a short code fetches the shared bundle online and opens a preview dialog so the recipient can review and accept incoming items (available in Full mode).

**For cross-device transfers, use online short codes.** Hardware NFC handoff depends on device support, foreground focus, and tag alignment, so always confirm that the recipient's preview dialog appears when testing NFC.

## Cards and organizations

Every organization card links directly to an active organization workspace—giving members a shareable entry point to its roster, roles and permissions, shared files, projects, and announcements. Before writing to a remote cloud library, the app verifies account ownership so existing libraries stay intact without creating duplicate folders.

Routine edits made across multiple devices merge automatically, and if two changes conflict on the same card or organization record, the app presents a side-by-side preview so you can choose which version to keep. Identity, membership, and file actions are enforced against real remote library permissions and verified with live multi-account testing alongside automated test suites.
