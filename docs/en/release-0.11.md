# 0.11 · Revolution


[中文](../release-0.11.md) · English

Version 0.11 introduces the Graphite visual theme built on OneGUI, three experience modes (Minimal, Practical, and Full), a language-first onboarding tour, and a unified introduction to search, OH, and plugins across every mode.

Full mode unlocks the freeform home whiteboard, tabs and OneGO, the staging box with online short-code sharing, organizations, plugins, and Xiaoda skill-plaza integration. The interactive tour demonstrates a live long-press drag using sample data, and the floating staging button can be repositioned anywhere on screen—highlighting gently as a drop target whenever you drag an item.

The OneShot bottom bar defaults to Study, Reservations, Life, Information, and Schedule. Assignment deadlines appear directly on the schedule in Minimal and Practical modes as well, and switching between modes keeps your Full-mode layouts, cards, and settings safely stored on your device.

In-app lightweight skills run inside a sandboxed pure-JavaScript QuickJS runtime, while multi-file or system-level skills can be exported to an external desktop agent. For sharing between devices, online short codes provide the most reliable transfer while NFC support continues to mature.

Screenshots across the public README and website are captured from the real app interface populated with sample data. Check [Releases](https://github.com/smartThise/OneTHU/releases/latest) for currently published installers and platform packages.
