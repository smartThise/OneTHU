# Android 小组件语言契约与验收


> 归档说明：本文记录当时的代码审查与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

日期：2026-10-20。本轮工作聚焦桌面小组件快照结构、Android 原生后台重绘与语言切换推送生命周期；测试全程在本地编译与内存模拟环境下完成，未写入真实手机桌面、未请求学校接口，也未改动个人日历数据。

## 已落地的契约与实现

- **精简快照内嵌词典**：`widgetSnapshot.ts` 在生成列表、详情、收藏夹与快捷方式快照时一并写入当前 `locale` 与 `widgetText`，顶层推送载荷及插件小组件槽位统一遵循该结构。快照仅随包携带小组件专用的 62 条文案模板，既免去拷贝整站庞大词典，也确保账户凭据绝不进入小组件存储。
- **CLDR 复数与纯文本插值**：`widgetText.ts` 按显式传入的语言码解析消息模板，时间与计数文案完整支持 CLDR 的 `zero/one/two/few/many/other` 六档复数分支，具名变量实行单遍纯文本替换。界面语言的切换仅改变展示文本，小组件实例 ID、日程事件标识、学校原始课程名、上课地点、时间戳、关系枚举与点击跳转目标均保持恒定。
- **原生后台重绘语言保持**：前端预览层的 `widgetNativeRender.ts` 与 Android 侧的 Kotlin `WidgetText.kt` 均严格读取快照自身携带的语言模板来重算日期抬头、开课倒计时、“正在上课”状态、剩余项计数与空状态提示。即便系统语言变化或主应用尚未唤醒，已落盘的英文或其他语种快照在后台定时刷新时仍稳定保持原语言；升级前缺少新字段的历史存量快照则平滑回退至中文模板。
- **语言切换主动推送与串行落盘**：`widgetRuntime.ts` 新增语言变更订阅，用户切换界面语言后立即触发重新采集与推送。若异步采集过程中语言再次切换，过期的旧世代快照会被直接丢弃；原生层写入操作按队列串行执行，确保先发出的旧任务落盘完毕后再由最新语言快照覆盖定格；运行时停止时同步解除订阅，并拦截尚在拼装中的半成品快照落盘。
- **详情卡片标题保真**：修正了原子详情小组件此前只要带有 `titleAt` 时间戳就在原生重绘时把原始标题改写为「今天」的问题；现在单条目详情始终保留原始标题，仅“今日日程”汇总列表按当前日期动态刷新抬头。

## 同步修复的存储边界问题

1. **槽位包装结构对齐与向下兼容**：此前前端 `widgetPush` 直接存入裸 `slots` 对象，而原生渲染器却从 `root.slots` 读取，两端结构存在错位。现统一改为存入包含 `slots`、`locale` 与 `widgetText` 的顶层包装对象，同时原生读取侧兼容历史裸 `slots` 结构，定时翻转点（flip time）扫描也会逐槽完整遍历。
2. **实例枚举失败防误删**：此前原生端在写入时忽略了前端传入的 `prune=false` 参数，一旦系统 Launcher 枚举当前桌面实例列表异常返回空集，便可能误删已保存的小组件配置。现已修正为仅当调用方显式传入有效 `instances` 数组且指定 `prune=true` 时才执行清理，遇到枚举异常或省略实例字段时一律完整保留既有配置。

## 词典翻译交接说明

小组件全部待译词条统一维护在 `apps/desktop/src/i18n/locales/*.ts` 的 `native.widget.*` 命名空间下（初始种子记录见 `docs/i18n/native-widget-seed.json`），共计 20 条普通消息模板与 7 组 × 6 档复数分支（合计 62 条）。英文词条在填入正式译文前会按设计自动回退显示中文，待后续翻译批次补入英文字符串后即可直接生效。

Android 资源目录下的 `src/main/assets/onethu-widget-zh.json` 由中文主词典自动导出生成，专用于为旧版历史快照提供中文兜底；日后若调整了中文源文案，运行以下命令即可同步刷新该资产文件：

```sh
node tools/i18n/widget-fallback.mjs --write
```

日常补充英文译文或未来扩展新语种时，只需更新前端语言包，无需改动任何 Kotlin 源码、快照协议或原生静态资产。翻译时请原样保留 `{count}`、`{month}`、`{day}`、`{time}`、`{title}`、`{remaining}`、`{slot}` 七个具名占位符（纯文本渲染，切勿混入 HTML 标签或 ICU 嵌套语法），为目标语种实际用到的每个复数分支填入自然译文并务必保留 `other` 兜底分支。`joiner` 作为界面显示分隔符可按语种习惯本地化，而底层的 `relation`、`type` 与 `target` 协议字段保持不变。
