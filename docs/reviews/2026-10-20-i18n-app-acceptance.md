# 语言切换与 OneGUI 验收


> 归档说明：本文记录当时的代码审查与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

OneGUI 组件库现已内置独立的语言 Provider，为内部 26 处默认界面文案与无障碍读屏标签补齐了完整的中英文默认值。宿主应用可按需注入自定义词典，组件库自身与桌面应用的国际化模块保持解耦；语言切换时组件树原地平滑更新，完整保留当前挂载状态。

运行 `node tools/gui-locale-test.mjs`，全部 65 项断言通过，覆盖默认中文回退、英文词条覆盖、多层嵌套 Provider、调用方显式传入内容优先保留以及真实组件的服务端渲染（SSR）。新增的非视觉导出项已在 OneGUI 架构护栏中明确归类，原有组件基线额度保持不变。

应用层验收分别在 `I18N_TEST_ENGINES=chromium` 与 `I18N_TEST_ENGINES=webkit` 下运行 `node tools/i18n-browser-test.mjs`，两轮均以退出码 0 自然结束，各通过 77 项断言（合计 152 项界面交互断言与两轮运行时零异常检查）：

- 在 Chromium 与 WebKit 双引擎下，交叉覆盖 `1280×900` 桌面视口与 `390×844` 移动视口，遍历完整、极简、实用三种界面模式。
- 通过真实语言下拉框切换界面语言后，文档 `lang` 属性与本地持久化配置同步更新，当前页面路由稳定保持。
- 完整模式下的收藏夹导入草稿与极简模式下的 API 输入框草稿在切语言后原样保留，底层输入框 DOM 实例维持同一引用。
- 点击真实的日程设置按钮唤起新建日程弹窗后，从另一个真实应用窗口切换语言，已打开的弹窗及正在编辑的草稿完整保留；点击取消后日历存储未产生多余数据。
- 切换至英文界面后，稳定的设置项锚点依旧准确定位，语言选择器在窄屏视口下完整可见且点击命中正常。
- 长译文压力用例仅在网络层替换英语词典返回模拟长句，保持真实生产布局与样式：标题正常折行、下拉框交互顺畅、页面无横向溢出，辅助说明文字继续按既有多行省略规则优雅收起。

测试报告归档于 [report.json](i18n-app-2026-10-20/report.json)，并已人工核查 [桌面设置](i18n-app-2026-10-20/chromium-1280-full-settings-en.png)、[手机日程草稿](i18n-app-2026-10-20/webkit-390-practical-editor-en.png) 与 [长译文夹具](i18n-app-2026-10-20/webkit-390-long-label-fixture.png) 三张实拍截图。

注：首次双引擎合跑在完成 Chromium 全部界面检查后，收尾阶段的 `browser.close` 偶发超出既有的 15 秒清理时限；随后保持完全相同的断言与 15 秒清理时限分引擎重跑，两轮均顺利正常退出。

本轮验收确认了国际化基础设施、已录入英文公共文案以及跨语言切换时的表单与弹窗状态保持能力。现阶段尚未填入译文的词条会按设计回退显示中文，因此截图中呈现中英文并存的过渡状态。测试全程采用隔离浏览器上下文与本地预览数据并阻断外网连接；`390` 视口与触摸事件仿真重点检验响应式布局表现，实体手机与各平台原生 WebView 将在发版真机环节进一步核验。

## 业务表单动态语言补验

仓库内全部 28 处业务 `openFormModal` 调用及插件门面入口的固定标题、字段标签、占位提示与下拉选项标签均已升级为消息描述符，使已经打开的业务表单也能实时响应语言切换。插件传入的自定义原始字符串与字段内容保持原样透传；选项的业务值（value）、用户已输入内容及字段初始默认值均维持原始数据不变。此外，组织加入表单的历史默认成员名“我”及空名提交回退值已固定为统一原始标识，避免将不同界面语言下的展示译文写入持久化的组织成员名单。

运行 `node tools/i18n-business-forms-browser-test.mjs` 以退出码 0 通过全部 28 项检查（含 3 项调用与持久化边界断言、24 项真实界面交互断言及 1 项运行时零异常检查）。测试在 Chromium `1280×900` 与 WebKit `390×844` 下，分别从通讯录与组织主页两条真实路径打开“新建组织”表单；在另一应用窗口来回切换中英文后，弹窗标题与三个字段标签即时刷新，表单容器及输入框 DOM 实例、已填写的组织名、简介与链接草稿均完好保留；切回中文并点击取消按钮后，组织数据快照无任何变动。

专项报告见 [业务表单 report.json](i18n-business-forms-2026-10-20/report.json)，人工复核截图见 [桌面通讯录表单](i18n-business-forms-2026-10-20/chromium-contacts-en.png) 与 [WebKit 手机组织表单](i18n-business-forms-2026-10-20/webkit-org-en.png)（均等待弹层入场动画稳定后截取；测试脚本初版曾将按钮名“新建组织”误写为“创建组织”并按 heading 标签查找标题，对齐真实 DOM 选择器后即一次通过，产品代码与断言强度均未变动）。

本专项通过为 8 个尚待翻译的词典键临时注入英文测试夹具，在保持真实业务组件与样式不变的前提下验证了延迟翻译链路；这 8 个词条的正式英文译文将在后续翻译批次中补入。测试全程以取消表单收尾，未改动任何组织状态，桌面端 TypeScript 类型检查亦顺利通过。
