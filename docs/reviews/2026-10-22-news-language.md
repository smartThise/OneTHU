# 新闻发布单位语言修复


本轮修复了中文界面下校内新闻列表与详情偶现英文发布单位名称的问题，已随 0.11.2 正式发布。

## 原因与机制分析

新闻解析器直接提取并展示学校接口返回的 `dwmc_show`、`fbdwmcList` 与 `text` 字段，而这些字段的语种取决于当前信息门户（Info）会话的语言状态。此前独立新闻页与首页新闻组件分别经由 `core` 与 `info-lib` 发起请求，两处均未根据当前应用界面语言同步门户会话语言，且本地新闻缓存键也未区分语种，一旦门户会话处于英文状态，中文界面便会一直沿用并缓存英文单位名称。

## 改动

- 为 `InfoClient` 的新闻列表、关键词搜索、订阅动态、发布单位列表及订阅条件读取接口统一增加可选的 `zh` / `en` 语言参数（默认中文）。
- 复用 `info-lib` 既有的 `/f/lang/change?websiteShowLanguage=` 门户语言切换接口（中文传 `awefawef`，英文传 `en_US`）：语言设置请求与紧随其后的数据读取共享同一个客户端串行队列，遇到会话过期自动重连后也会重新同步一次语言；若语言切换请求失败则直接结束当次读取，保持后续队列畅通。
- 首页新闻组件统一收敛至该客户端入口；首页订阅列表改按服务端订阅条件 ID 分页拉取并合并，即便本地曾存有英文单位标签，切回中文界面后依然能完整加载全部已订阅内容。
- 新闻页与首页新闻改用包含版本号与语言维度的缓存键，自动隔离旧版无语种缓存；切换界面语言或翻页时立即清空旧视图占位，迟到的旧语言请求结果仅写入其自身语种对应的缓存槽位。
- 发布单位选择器、订阅筛选栏与新闻搜索结果均随界面语言切换实时刷新：刷新订阅条件期间保持已选单位 ID 不变，待最新语种的权威单位列表到达后再开放变更；已打开阅读的新闻正文保持不动，顶部的来源单位元信息随列表同步更新。
- 英文及其他非中文界面统一请求并展示学校提供的英文发布单位名称；新闻标题、正文内容、附件文件名及搜索关键词始终忠实保留原文。

整个流程仅在当前已建立的门户会话上同步显示语言偏好，无需额外发起登录或重传账号凭据。
