# 英文官网与导览素材修补


## 问题与实现

此前英文版官网和导览仅切换了说明文案，设备模型屏幕与操作演示仍沿用中文素材。本轮基于真实英文界面与全套英文虚构课程、作业、人物、组织、技能数据，单独采集了全套截图并实录了长按拖入暂存箱的演示视频，原有中文文件完整保留。所有画面均由真实英文 UI 在离线隔离环境中渲染生成。

- 官网、英文 README 和英文文档均引用 `en-US` 专属图片与视频。
- 导览 31 个屏幕均提供独立英文版本；WebGL 模型、无 WebGL 降级画面以及“减少动态效果”下的静态画面统一采用对应语言的素材源。
- 图片解码缓存按语言隔离；切换语言时自动卸载旧模型贴图及视频，防止迟到的旧语言异步加载结果覆盖当前界面。
- 所有非中文导览语言统一展示英文演示素材，中文界面展示中文演示素材。
- 新建暂存箱默认名称、组织默认成员名、作业/通知/文件的暂存来源标签以及清小搭默认助手名均已接入现有词典；同步补齐了搜索结果分组、实用模式说明回退与外部作业平台名称的展示层翻译。用户已保存的自定义名称与外部原始内容保持原貌，随用户数据原样展示。
- 采集脚本采用语言参数、独立临时浏览器上下文、固定模拟时间、外部请求阻断与 SHA-256 清单核验；英文素材采集完成后逐张核对可见文字，确保无中文残留。

## 重现

详见 [素材采集说明](../screenshots.md)。设置 `ONETHU_CAPTURE_LOCALE=en-US` 后运行 `capture-public-preview.mjs`、`capture-localized-tour.mjs` 与 `record-vault-onboarding.mjs` 即可采集全套英文素材；官网仓库运行 `sync-preview-assets.py --locale en-US` 可在校验哈希后同步生成 WebP 资源。
