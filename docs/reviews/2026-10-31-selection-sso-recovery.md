- 后台诊断原因为 `CAMPUS_SERVICE_IDENTITY_REQUIRED`，此前统一映射成 `GATEWAY_SERVICE_SSO_REQUIRED`，用户无法分辨具体原因。

## 已修正的代码问题

通用漫游之前按完整 origin 比较业务回跳。旧选课实现已记录：HTTP 业务可能收到同主机 HTTPS CAS 回跳地址，实际兑票必须使用原先 HTTP 服务的 WebVPN 路线。旧校验会把它当成跨服务回跳拒绝，即使 ID 登录正常也会卡住。

现在仅在官方入口先确定 HTTP 服务、身份认证后返回同一主机的 HTTPS 回跳时，保留已发现的 HTTP 上游路线，同时维持浏览器的 HTTPS 地址和原票据。不同主机仍拒绝，最初为 HTTPS 的业务也不能借此降成 HTTP。处理不依赖选课名称或应用 ID，可用于同类旧服务。

`CAMPUS_SERVICE_IDENTITY_REQUIRED` 单独映射成 `GATEWAY_IDENTITY_SESSION_REQUIRED`。顶层 HTML 导航显示中英双语的学校登录恢复说明、手动重试与返回 Info；API 请求保留明确的 JSON 错误码。页面不回显原 URL、响应正文或凭据，禁止缓存、脚本、嵌入与表单提交，也不自动重复登录。此修改仅改进错误归因与恢复入口，不会凭空生成认证票据。
