# 手机操作与布局修复 · 2026-10-22


本批修复已随 0.11.1 正式发布，最终构建源码、三端安装包哈希与渠道核验详见[发布执行记录](2026-10-22-release-0.11.1.md)。桌面端继续保持原有的导航结构与白板编辑交互。

## 问题与处理

| 反馈 | 原因及修复 |
| --- | --- |
| 检查更新变成空白灰按钮 | OneGUI 原 loading 样式同时隐藏了按钮文字、清空字色，而加载转圈图标缺少实际尺寸与绘制样式。现改为保留文字并正常绘制旋转指示器，同时展示当前检查源；主源限时 8 秒、备用源限时 15 秒，支持随时取消与重新检查，迟到的旧响应会自动丢弃。 |
| 点击“管理组织”或编辑无响应 | 从设置页发起跳转时，目标页面被打开在尚未关闭的设置浮层下方。现新增专用导航方法，跳转前先收起设置浮层，并通过完整的新建组织与编辑表单流程验证可达性。 |
| 编辑白板时突然跳成电脑端缩放 | 旧逻辑在进入编辑态时会将尚未保存过缩放比例的手机自由画布强制放大至 500%。现已移除该跳变，自由摆放首次进入默认按 100% 适配当前视口，同时保留用户已有的缩放设置；Android 端跟随系统屏幕朝向，打字输入时稳定保持竖屏阅读布局。 |
| 白板编辑入口套了两层外框 | 浏览状态下的工具栏移除了多余的外层边框、阴影与底板材质，清爽展示带画笔图标的编辑按钮。 |
| 白板缺少撤销与恢复默认功能 | 新增按白板及屏幕朝向独立隔离的会话级撤销栈：自动拟合不占用撤销步数，连续文字输入自动合并为一步，外部数据写入时自动清理过期历史。支持将首页恢复为默认组件与布局、将自建 OnePage 清空重置（操作前均带二次确认，且恢复动作本身也支持撤销）。 |
| 暂存箱容易遮挡屏幕正文 | 手机端将暂存箱拖至距左右屏幕边缘 24px 以内松手时，会自动贴边吸附并半收起；半收起状态下轻点一次即可直接打开管理面板，拖回屏幕中部则恢复自由悬浮（文件传输进行中保持完整展开，桌面端维持自由摆放）。点按与拖拽的位移容差与强制刷新悬浮钮统一对齐：鼠标 10px、触摸 12px。 |
| OH 悬浮窗收起按钮不易辨认 | Android 原生悬浮窗换用高对比度图标与文字标签，按钮触控高度提升至 44dp，文案随当前应用语言动态切换。 |
| 手机端希望提供列表式导航 | 支持通过左上角按钮呼出临时的纵向功能浮层来替代底部 OneShot：极简模式展示五项核心入口，完整与实用模式展示全部一级功能区，底层页面始终保持全宽。三种模式各自保存导航偏好，完整与实用模式的新手导览也加入了布局选择。详见导航更正报告。 |

手机端新手导览在选定使用模式后紧接着提供导航布局选择，从第一节导览点击返回时仍可重新调整；导航偏好保存在设备本地，原有的白板排布、OneShot 快捷项及其他模式配置均完好保留。此外，实用模式与极简模式的精简设置页也同步补入了软件更新入口。

## 验证

- 基于真实 React 界面与匿名模拟数据：在 390px 手机视口下完成白板编辑布局、撤销、恢复默认、新建与编辑组织、检查更新加载态及中途取消等 7 项端到端检查，全部通过。
- 首页与 OnePage 触摸编辑：覆盖 390px 竖屏与 844px 横屏，验证浏览态防误触锁定、原生触摸滚动、编辑态真实拖拽与缩放、多白板独立编辑、退出编辑、返回键收起及桌面端原有交互保持，共 30 项全部通过（含文本框聚焦后模拟软键盘压缩视口高度的场景）。
- 多宽度布局与暂存箱贴边：在 320 / 360 / 390 / 430px 视口下实测完整与实用模式的导航入口点击、暂存箱贴边吸附、半收起点击展开与拖回中部自由放置，结合逐组件包围盒边界与极窄屏复核共 43 项通过；其中早期常驻侧栏方案随后已按用户反馈升级为全宽浮层方案，导航部分的最终验收以[更正报告](2026-10-22-mobile-navigation-correction.md)为准。
- 导览布局选择：320px 英文界面下的导航布局选择、继续与返回流程通过，桌面端自动跳过手机布局选择页；极简导览保持直接进入功能介绍，并支持后续在设置中切换导航。
- 全量导览跳转：覆盖搜索、白板、暂存箱、口令、NFC、组织、清小搭、工作区、OneGO、插件、外观、学习、数据等模块的桌面与手机端真实跳转，共 66 项通过。
- 悬浮按钮手势细节：覆盖强制刷新按钮与暂存箱在桌面及手机端的常规点击、微幅手指抖动、长按慢抬、拖拽落点、手势取消、页面刷新后位置恢复及键盘操作，共 85 项通过。
- 状态机与单测回归：更新检查覆盖主源超时回退备用源、双源超时提示、中途取消、预取消及失败后重试成功；白板历史栈覆盖连续打字合并、自动拟合、外部写入与横竖屏隔离；二级课表 11 项、节次锚点 14 项、系统日历 28 项回归全部通过。
- 工程与多语言护栏：TypeScript 类型检查、OneGUI 单源与对比度护栏、中英文各 7572 个词典键校验、62 条 Android 小组件本地兜底文案检查全部通过；Android 原生 OH 悬浮窗 Kotlin 代码编译通过。

## 截图复核补充

在复核早期 320px 侧栏方案截图时，曾发现白板容器虽通过了外框宽度断言，内部卡片却因 240px 最小宽度下限而超出剩余可用宽度发生裁切。为此已将阅读态投影改为按容器实际可用宽度自适应，并在测试中补充了逐组件的包围盒越界断言，同时完整保留底层存档中的原始坐标。随后导航升级为覆盖式抽屉浮层，主页面也恢复了完整的全屏宽度。
