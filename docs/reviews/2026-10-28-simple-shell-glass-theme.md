# 极简与实用壳的玻璃、主题字色（2026-10-28）

## 起因

玻璃程度调到「透光」或「透彻」时，实用与极简模式的顶栏、底栏、设置浮层仍然是不透明的；夜间主题下首页的大字小字依旧是深色，换成别的深色主题也不跟着变。

## 为什么只有这两个壳不对

两处都是「壳自己写死了一层样式」，与玻璃和主题配方打架：

- 底栏在简单壳里被显式画成画布底色，而且规则位置在后、与玻璃配方同权重，后者被压掉——表现为元素带着背景模糊却一点都不透光。顶栏更彻底：它压根不在玻璃配方那张选择器名单里（完整模式用的是另一套顶栏结构）。
- 壁纸亮度档会把「反色锁」以内联样式挂在壳根节点上：亮壁纸压白、暗壁纸压黑。完整模式的栏体有自己显式的字色，简单壳的标题靠**继承**，于是直接把锁里的深色继承下来，主题令牌没有机会生效。这也解释了它为什么只在有壁纸时出现。

## 做法

玻璃配方按简单壳的作用域补齐：顶栏与底栏在玻璃档改用填充令牌加背景模糊，平衡档（默认）不落属性，维持原来的中性面。

字色只跟主题令牌走：主文与次要文各取一档，首页的两处容器标记为不参与反色锁定，对比度引擎不再往里面塞内联颜色。

设置浮层给实用模式的面板加一个模式类，标题栏与内容列吃同一套玻璃配方。选择器与原来的「三栏实心」规则同形并高一级，否则会被实心表面令牌压回去。

## 边界

新增规则全部挂在简单壳与实用模式的设置面板上，完整模式一行没动：内容列仍是实心白、标题栏仍实心、只有左导航是玻璃，与改动前一致。极简模式共用同一套壳，一并修好。

## 验证

安装包实测（1240×821，DPR 1.75）：玻璃档选「透光」后顶栏与底栏透出壁纸，设置面板的标题栏与内容列同为玻璃面；切到夜间主题，首页大字为白、小字与日期为次要色。当时的两张截图因为带着本机的壁纸与待办清单，只留本地、不入库。
