# perf(glass): 页面级预计算模糊（dev3）

> Base：`dev3`（`cfeaac4b`，已包含 #64 的 UI/材质收敛）  
> Branch：`xiao-dreamr:perf/preblur-glass`

## 概要

把页面级大面积玻璃从“每张卡实时 `backdrop-filter`”改成“壁纸预模糊位图 + 固定背景”，只保留需要实时采样内容的玻璃区域。

## 实现

- 新增 `apps/desktop/src/lib/preblur.ts`：
  - 图片壁纸加载后一次性生成 **deep 24px / rich 14px / clear 6px** 三张模糊位图；
  - 最长边限制 1600px，按壁纸 ref 缓存；
  - 本地 `local:` / asset 壁纸优先 fetch 成 Blob 再 `createImageBitmap`，避免 canvas 污染；
  - 生成失败时自动回退实时 backdrop。
- 新增 `apps/desktop/src/styles/preblur.css`：
  - 大面积页面材质（`.og-surface`、`.og-pagehead`、`.free-item` 卡片、`.workbench-board-head`）使用固定定位的预模糊位图 + 档位 tint；
  - 去掉这些面的 `backdrop-filter`。
- `ShellWallpaperLayer` 在图片壁纸就绪后写入 `data-og-prebblur="on"` 和三个 CSS 变量；离开图片壁纸/视频壁纸时清除。
- 实时玻璃保留：
  - 设置面板 / `.workbench-settings`
  - OH 搜索 `.ohx-searchpane` / `.ohx-capsule`
  - 暂存箱 `.vault-page` / `.vault-manager` / `.vault-sheet` / `.vault-workspace`
  - 浮层/面板 `.ex-sheet` / `.theme-pick-panel` / `.og-panel` / `.og-float`
  - 顶栏 / 标签栏本身不在此次 preblur 目标内，继续保持自己的实时材质。
- 无图片壁纸、视频壁纸、canvas 失败或 `prefers-reduced-transparency` 时保留原实时 backdrop。

## 验证

- 图片壁纸实测：课程页实时 `backdrop-filter` 元素从 10–14 个降到约 **7 个**（顶栏、底栏/胶囊、收藏栏、少量浮动按钮）。
- 设置面板内 `.og-surface` 仍为 live `blur(...)`，背景 `scroll`；页面卡为 `none` + `fixed`。
- 顶栏/标签栏/OH 胶囊/收藏栏保持 live。
- `glass-optics-test` 32/32 ✓
- `glass-surfaces-test` 60/60 ✓
- `preblur-test` ✓
- `typecheck` ✓、`i18n` 0 errors ✓、CSS parse ✓

## 风险

- 预模糊只适合静态图片壁纸；视频壁纸自动回退实时。
- `background-attachment: fixed` 在极端 transform 动画中可能有短暂对位差异；静止状态验证正常。
- 预模糊位图内存约三张 1600px JPEG；按 ref 缓存，壁纸切换时释放 CSS 变量。
