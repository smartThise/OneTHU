# OH 应用能力接入审查（2026-10-26）


## 触发与根因

用户先后转述 OH 提示「雨课堂没接入」「没有好友列表接口」，并要求一并检查组织、清小搭和暂存箱的接入状况。

排查确认两类问题同时存在：雨课堂虽已内置工具，但模型沿用了历史对话中的错误判断；通讯录、组织、清小搭技能广场和暂存箱则确实缺少完整的公共服务接口。原有的 `skills_search` 仅检索本机已启用且可运行的技能，未覆盖清小搭在线技能广场；扩展插件、本地技能与页面搜索也只各自覆盖局部入口，缺少统一的内建服务目录。

## 统一入口

新增 `app_services` 与 `app_call` 两个工具，复用已审核的 CLI 服务边界，涵盖参数校验、账号代次、结果凭据脱敏与操作审批。宿主每轮动态注入当前实际注册的服务名，原有专用工具继续保留；当前静态目录共 161 项，并整合了既有的 Learn 与常驻任务服务。

应用内部 OH 通过宿主进程内通道调用上述能力，无需开启对外 CLI 监听；内部调用标记仅由宿主组合代码直接注入，忽略外部请求 JSON 传入的同名字段。关闭智能体授权后读写均立即停用，常驻后台任务仍受 CLI 开关控制。服务目录仅开放经显式登记的业务操作，屏蔽未知操作、未登记命名空间、底层原始存储与通用网络透传；`app_call` 的写操作统一由服务端真实审批结果决定放行，需经用户实际确认后方可执行。

新增功能说明与调用边界见 `docs/oh-app-services.md`，英文版见 `docs/en/oh-app-services.md`。

## 本轮功能覆盖

| 类别 | 接入结果 |
| --- | --- |
| 好友 | 当前账号的 OneTHU 通讯录列表、筛选、名片详情；默认个人好友，组织名片可选 |
| 组织 | 索引与详情、实时远程成员核验、项目、公告、关联云盘与 GitLab 引用；本地创建、资料编辑、项目与公告增改删 |
| 清小搭 | 登录状态、智能体、模型、余额、历史会话、技能广场分页搜索与详情、已安装技能、导入、启停、删除、经批准向真实智能体提问 |
| 暂存箱 | 箱子及条目查询、所选内容、UTF-8 分页读取；新建、改名、存文字、存原子引用、验证后存云盘文件、移除条目、生成或复用短口令、接收到新箱 |
| 旧版专用能力 | 学校查询、雨课堂、搜索与导航、白板、OnePage、OneGO、标签/工作区、主题、插件、OneFlow、常驻任务保留，并通过能力检索可发现 |

涉及系统文件选择、扫码/NFC、修改组织成员角色或变更共享空间授权的流程，继续引导用户打开对应功能页面完成。组织的 `create` 操作负责创建本地组织索引（创建并授权云端共享空间需在组织页面完成）；暂存箱口令接口专注于箱子内容的生成与接收，好友添加、组织邀请及口令外发仍由用户在对应页面操作。

这批新增数据源直接挂载在运行中的 App 进程内，独立 CLI 守护进程则按其自身注册目录提供服务。

## 数据与安全修补

- 新增八项独立权限：`contacts:read`、`org:read/write`、`xiaoda:read/manage/chat`、`vault:read/write`；同步更新两份内置 Harness 清单、插件验证白名单与中英文权限说明，兼容用户既有设置。
- 好友及组织查询校验个人资料归属，并同步核实完整模式、学校账号、原生会话代次与关联云盘凭据状态；远程组织拒绝访问时直接返回真实错误，避免回退旧缓存掩盖权限变更。
- 名片结果剔除头像原图、共享口令、通信通道与历史分享记录；组织结果剔除邀请码与共享凭据；暂存箱剔除内部原始 payload、私有暂存路径与分享凭据，执行分享操作时仅显式返回所需短口令。
- 组织写入复用实时角色检查与内容版本校验，并在读取 GitLab CSRF 后、正式提交前再次执行状态 guard；原页面调用未传 guard 时保持既有行为。
- 清小搭提问先校验真实 agent id，经用户确认后才创建会话并发送文本；导入与启停保留原生技能兼容性门禁。技能检索移除原有的 30 项静默截断，广场接口完整保留显式页码与学校服务端分页元数据。
- 暂存箱文本读取返回总字符数与下一段游标，UTF-8 文件读取显式限制为 8 MiB；针对旧版交换协议单条文字 4096 字符的上限，改为在分享前直接报错拦截，避免接收端静默截断。移除暂存条目仅清理箱内引用，保留原始文件与源对象。
- 分享流程的创建资料库、上传文件与生成链接各阶段均支持逐步 guard；遇到操作取消或账号切换时立即中止后续发布，确保分享记录严格归属原发起账号。OH 接入适配器时默认关闭附加的过期分享清理。
- 目录分享仅在服务端明确因策略拒绝时降级为单文件分享；遇到 HTTP5xx 或超时等未决状态时直接返回错误，避免重复创建额外链接。
- 更新常驻任务说明：桌面端在常驻后台保持运行时支持退出主窗口后继续执行，移动端任务则随应用前台运行周期执行。

## 实际验收与限制

在原 dev 环境通过真实公共服务边界完成只读验收：成功读取 1 个好友、1 个组织、1 个暂存箱（6 项）；清小搭技能广场第一页返回 20 项（总计 273 项），本机已安装技能为空。真实姓名、组织内容和会话信息仅保存在用户本机私有临时目录，未写入仓库。

使用原问题调用真实 `askOh` 时，当前 MadModel 返回 HTTP502；随后使用同一学校会话与模型发起不带工具、不带历史记录的最小请求，同样返回 HTTP502（`error.type=server_error`），确认故障源于上游模型服务端，与本轮新增的工具参数及好友接口无关。验证期间保留了用户原有的模型提供方、对话历史、已装插件及扫码绑定状态。

综上，本轮新增的真实数据接口均已联调验证通过；上游模型问答恢复与微信通道的新消息端到端回复留待 MadModel 服务恢复后复核。源码中的临时验收模块与入口已全部移除，全程未发送微信消息，也未执行技能安装、组织修改或真实分享创建。

最终构建已加载至原 dev 实例，页面与既有 OH 对话历史正常恢复，应用资源与实际部署的 Harness 二进制 SHA256 一致：`aa106b9eac0e10d0985e83f70383ee3b8efbc9491a37f467e30f5a98722e2b3f`。
