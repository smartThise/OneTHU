# 学校英文页面解析、展示身份和诊断隐私


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。

本轮改动保持学校接口返回的数据、请求字段与远端语言偏好原样不变。界面优先展示学校提供的 `englishName`，解析器同时兼容中英文展示标签，提交操作则以明确的成功标记为准。

## 样本范围与测试环境

用户提供的两份参考样本分别为包含官方语言切换入口的网络学堂英文课程首页，以及 Info 信息门户英文首页。仓库中仅提炼匿名页面结构，未留存附件中的个人课程、姓名、CSRF、票据或原始 HTML。

由于样本尚未涵盖英文选课结果表与英文作业详情内页，本轮验证聚焦于匿名页面结构下的英文表头兼容、会话状态识别与异常保护，全过程均在离线隔离环境下进行，未登录真实账号操作语言设置、提交作业或执行选退课。英文全站内页的实机表现留待获取对应样本或实机联调后进一步确认。

2026-10-20 执行匿名网页复核时，[网络学堂课程入口](https://learn.tsinghua.edu.cn/f/wlxt/index/course/student/)正常返回未登录提示，Info 与选课入口则因需校园认证而无法通过匿名抓取直接读取内页；登录态下的完整页面交互仍需在真实校园会话中核实。

## 改动

- 网络学堂作业提交严格以机器字段 `result: "success"` 判定成功；遇到英文拒绝提示、未知 JSON 结构、空对象、数组或非 JSON 响应时均按失败处理，提交正文与 multipart 字段保持原样。
- 作业详情解析同时兼容中英文提交内容标签，并保留 `textarea[name=zynr]` 这一与界面语言无关的提取路径。
- 选课表格支持按中英文表头映射列位，可识别英文会话失效、业务拒绝与分页信息。选课后的回读校验需同时匹配课号与归一化课序，遇到显式拒绝时直接报错，防止旧课程缓存掩盖失败结果。
- 退课操作须在成功识别结果表、完整解析所有数据行并确认目标课号与课序已移除后才判定完成；若遇到未知页面结构或身份控件发生变化的表格，均按异常处理以防误判为空课表。志愿调整同样通过回读目标值确认结果。
- 学堂、HTTP 与选课行解析的诊断日志仅记录固定状态码、响应类型、长度与条目计数，移除了作业正文、原始 HTML/JSON、脚本、姓名及完整 URL 查询串；上层业务调用方依然接收完整的原始响应与解析数据。
- 中文界面使用原课程名；英文及其他非中文界面优先展示学校提供的英文名，缺失时自动回退至原名。搜索保持中英双语匹配，底层缓存对象维持不变。
- 作业、通知、文件的共享行组件新增 `identityCourseName` 字段，由调用方传入原课程名作为稳定标识，界面展示名仍可随语言切换。暂存箱按完整 Atom 键去重，切换语言后同一条目可准确识别，避免重复存入；收藏模块本身已按身份字段规范化，切换语言同样保持唯一。

## 界面文案补漏

对显式 JSX 文本和静态展示属性的扫描确认已无遗漏的硬编码中文；继续排查动态表达式后，补齐了 ICS 导出、文字预览默认标题、OH 搜索占位，以及微信/飞书适配器标签、二维码状态和本地错误回退提示。新增的 19 条双语词条存于 `docs/i18n/gui-completion-seed.json`，由总词典统一合并。

插件状态提示色改为根据 `failed` 布尔状态驱动，取代原先基于中文失败文案的字符串匹配；更新失败后也会立即释放忙碌状态以便重新尝试。协议值、设置身份、外部消息正文、日志与学校状态判定均保持原样。扫描范围与处理记录见 [ui-residual-review.json](school-language-2026-10-20/ui-residual-review.json)；本记录聚焦于源码硬编码文案的清理，词典中尚未补充英文译文的键在运行时会自动回退显示中文。
