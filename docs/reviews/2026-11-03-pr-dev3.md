## 3. 材质、玻璃与折射

### 3.1 材质稳定性

- `80c8b171` 修复材质/字色首帧漂移，入场动画只动 transform。
- 嵌套玻璃面去重：`.og-surface--l1/l2/l3/sunken`、卡内 `.og-surface`、卡内段轨/搜索框/outline 按钮不再重复开 `backdrop-filter`，只保留外层一次模糊；overlay 例外。
- 旧 `#dsh-liquid-refract` / `--glass-refract` 退役，毛玻璃 blur 与光学折射彻底分离。

### 3.2 光学折射开关

- 设置 → 外观新增「光学折射」，**默认关闭**；
- 三种玻璃档可用，实心档禁用；
- 关闭只释放 OneGUI 边缘折射 lens，普通毛玻璃 blur 保留；
- 开启后 lens 使用该档原始 blur，位移只改变采样位置；候选面覆盖 `.learn-course-card`/`.og-pagehead`/`.og-surface`，同时上限 8 个面；
- 设置项带 GPU 性能提示；实测关闭折射后 1% low 显著恢复。

### 3.3 材质档位改名与梯度

| 档位 | 数据值 | 模糊 | 纯色遮罩（亮/暗） |
|---|---|---|---:|
| 实心 | `balanced` | 关闭毛玻璃 | 实色中性面 |
| 磨砂 | `deep` | 24px | 80% / 40% |
| 雾面 | `rich` | 14px | 52% / 26% |
| 玻璃 | `clear` | 6px | 24% / 14% |

- 从磨砂 → 雾面 → 玻璃：模糊递减、透光递增；
- 档位存储 id 不变，老用户的设置不需要迁移；
- 阅读面、overlay 遮罩同步调整。

### 3.4 Tab 几何

- 分段轨外壳也改为 `corner-shape: squircle`（此前只有内胶囊是）；
- 外 14px / 内 11px 同心；指示器 left 扣除宿主 border，黑胶囊与激活项严格对齐；
- 补回分段轨 12px 下边距；
- 课程双来源 tab 回归 21 项通过。
