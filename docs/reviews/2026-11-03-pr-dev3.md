## 3. 材质、玻璃与折射

### 3.1 嵌套材质去重

- `.og-surface--l1/l2/l3/sunken`、卡内 `.og-surface`、卡内段轨/搜索框/outline 按钮不再重复开 `backdrop-filter`，只保留外层一次模糊；overlay 例外。
- 旧 `#dsh-liquid-refract` / `--glass-refract` 退役，毛玻璃 blur 与光学折射彻底分离。

### 3.2 光学折射开关

- 设置 → 外观新增「光学折射」，**默认关闭**；
- 磨砂/雾面/玻璃三档可用，实心档禁用；
- 关闭只释放 OneGUI 边缘折射 lens，普通毛玻璃 blur 保留；
- 开启后 lens 使用该档原始 blur，位移只改变采样位置；候选面覆盖 `.learn-course-card`/`.og-pagehead`/`.og-surface`，并行上限 8 个面；
- 设置项带 GPU 性能提示。

### 3.3 材质档位改名与梯度

| 档位 | 数据值 | 模糊 | 纯色遮罩（亮/暗） |
|---|---|---|---:|
| 实心 | `balanced` | 关闭毛玻璃 | 实色中性面 |
| 磨砂 | `deep` | 24px | 80% / 40% |
| 雾面 | `rich` | 14px | 52% / 26% |
| 玻璃 | `clear` | 6px | 24% / 14% |

- 从磨砂 → 雾面 → 玻璃：模糊递减、透光递增；
- 档位存储 id 不变，老用户设置不需要迁移；
- 阅读面、overlay 遮罩同步调整。

### 3.4 Tab 几何

- 分段轨外壳也改为 `corner-shape: squircle`（此前只有内胶囊是）；
- 外 14px / 内 11px 同心；指示器 left 扣除宿主 border，黑胶囊与激活项严格对齐；
- 补回分段轨 12px 下边距；
- 课程双来源 tab 回归 21 项通过。

## 7. 风险与回滚

- **无数据迁移**：玻璃档存储 key/id 不变；光学折射新增 key，缺省为关闭；FPS 开关仅 dev 使用。
- **默认行为变化**：光学折射此前开启，现默认关闭；这是有意为之，避免默认性能回退。
- **视觉变化**：玻璃档位改名及 blur/alpha 梯度；如果用户不接受，可单独回滚 `e18f89c6`。
- **CSS**：`--glass-refract` 已移除；外部若直接引用该变量需改为普通 blur 或 `--og-refraction-*`。仓库内无外部消费者。
- **回滚**：按提交组回滚；材质/折射集中在 `67dc8c32`、`c34385dc`、`d1655efc`、`e18f89c6`。
