# 外部作业源

> 最后更新：2026-11-18 01:30

清华大学的课程作业分布在多个教学平台中：除网络学堂外，雨课堂承载日常课堂练习与试卷，TUOJ 承载编程作业（分为 AI 版与经典版两个站点实例），Tyche 承载部分院系的课程作业，DSA OJ 则承载数据结构课程的在线评测作业。

外部作业源模块将上述平台的任务统一汇聚到应用的作业页面，集中展示截止时间、提交进度与批改得分。插件可通过 `onethu.exthw.snapshot()` 与 `onethu.exthw.refresh()` 读取和刷新聚合结果（详见 [api-reference.md §4](./api-reference.md)）。

本文档介绍各作业源的登录接入方式、状态判定规则、会话异常恢复机制，以及接入新作业源的开发步骤。

## 1. 数据模型

所有外部平台的条目统一映射为 `ExternalHomework` 结构：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 源内唯一标识，用于列表去重 |
| `source` | string | 源标识，见 §2 |
| `courseName` / `title` | string | 课程名称与作业标题 |
| `deadline` | string | 截止时间，格式 `"YYYY-MM-DD HH:MM"` |
| `kind` | `"homework"` \| `"exam"` | 作业或试卷类型 |
| `url` | string? | 学生端详情页链接 |
| `submitted` | boolean | 提交状态 |
| `submittedCount` / `totalCount` | number? | 已提交题数 / 总题数（雨课堂提供精确题数统计） |
| `graded` | boolean? | 批改状态（雨课堂与 Tyche 支持判定） |
| `audited` | boolean? | 是否属于旁听课堂（雨课堂 `role===6`） |
| `score` / `totalScore` | number? | 实际得分与卷面满分，**仅在已提交且已出分或已批改时填入** |
| `leafTypeId` / `classroomId` | string? | 雨课堂整卷明细参数，供原生详情页拉取正文 |

## 2. 源与登录方式

| 源 | 标识 | 登录方式 | 恢复机制 |
|---|---|---|---|
| 雨课堂 | `yuketang` | 微信扫码登录（长轮询）或官方网页登录（应用内 WebView 读取 Cookie）；官方短信通道已下线并启用了图形验证码 | 网络抖动中断后沿用原令牌继续轮询；移动端通过前台服务维持连接 |
| TUOJ（AI 版） | `tuoj` | 默认复用清华统一认证会话漫游，也可单独配置 TUOJ 独立账密 | 接口返回 401 / 403 时自动重新漫游一次 |
| TUOJ（经典版） | `tuojClassic` | 同上 | 同上 |
| Tyche | `tyche` | 复用清华统一认证会话漫游 | 同 TUOJ |
| DSA OJ | `dsa` | 站点独立邮箱 + 密码登录，也支持手动填入会话 Cookie | 会话过期时抛出 `DsaSessionError`，并在页面引导重新登录 |

## 3. 状态判定

**提交状态**：由各源客户端独立向远端查询。若接口请求失败或当前账号缺少读取权限（如部分受限的雨课堂试卷），统一保守归为「未提交」，防止误报已交导致漏做作业。DSA OJ 目前同样采取保守策略：其 `assignment.status` 字段的线上取值含义尚待真机联调确认（见 R15 20.1 记录），现阶段统一显示为未提交。

**批改状态**：

- **雨课堂**：读取 `get_exercise_list` 返回的 `status` 字段（取值为 4 或 3 代表已批改），并结合分值占位符综合判定；作业与试卷的外部详情链接指向学生端 `/ai-workspace/lms-graph/...`。
- **Tyche**：读取 `task/Status` 接口返回的 `submissionList[]`（含 `pid`、`score`、`result`、`submitedTime`），按题目 `pid` 选取最新一次提交记录汇总；当所有题目均取得有效分数时标为已批改，`score` 为各题得分之和。
- **DSA OJ**：课程详情接口返回的 `assignmentList[]` 仅包含标题与截止时间，未提供得分字段，因此 `graded` 与 `score` 保持为空。

## 3.1 雨课堂原生详情与提交入口（R20–R21）

雨课堂的题目正文混合了自定义加密字体、LaTeX 公式与鉴权外链图片，直接在内嵌网页中打开容易出现缺字、公式丢失或图片 401 报错。自 R20 起，雨课堂升级为**应用内原生详情页**，直接在本地完成正文解析与排版：

| 能力 | 实现要点 |
|---|---|
| 题干渲染 | 正文放入无网络权限、启用脚本白名单的本地 `srcdoc` 沙箱 iframe；从接口 `data.font` 下载加密字体（`exam_font_<hash>.ttf`）并以 `@font-face` 注入，本地缓存 7 天，拉取失败后冷却 10 分钟再试 |
| 公式 | 内置按需加载的 KaTeX（`vendor/katex`），在本地直接渲染 `$…$` 与 `$$…$$` 数学公式 |
| 图片 | 由应用侧携带会话 Cookie 代理下载后转为内联 `data:` URI，避免沙箱内请求触发 401 |
| 降级容错 | 字体、公式或图片任一环节加载异常时自动逐级回退为纯文本与提示条，**始终保持题干清晰可读** |
| 分数与评语 | 已批改作业在列表入口直接显示 `X/Y` 得分（与试卷位置一致）；详情页逐题展示得分、本人作答与教师评语，并对总评与具名批注中的重复文本自动去重 |
| 提交入口（R20-C1，第一阶段） | 通过内嵌官方作答页（`WebView`）并注入当前会话 Cookie 完成作答，可提交资格由纯函数统一判定 |
| 主观题原生作答（R20-C2，第二阶段） | 支持在应用内直接编辑与提交主观题（工具栏对齐官方，支持拍照等四通道插图、KaTeX 公式、本地草稿与剩余次数提示），经用户弹窗确认后调用官方提交接口；设计与实测见 [外部作业源-需求与实现方案.md §31](./外部作业源-需求与实现方案.md)，使用说明见 [homework.md §4](./homework.md) |
| 会话保活（R21-B） | 提供会话健康检查、后台保活及 Cookie 导出/导入能力，减少打开作业时登录态过期的等待；Tyche 登录过期时自动静默重漫游（R21-A） |

**功能范围与学术诚信说明**：外部作业源的列表与试卷详情均为只读展示视图，负责呈现标题、课程、截止时间、提交批改状态及题干内容；**考试与试卷全程隐藏作答入口**。主观题原生作答仅服务于学生本人亲笔撰写与手动确认提交，应用负责排版渲染、插图上传与请求发送；完整的学术红线与工程护栏见 [homework.md §5](./homework.md)。

## 4. 会话失效恢复

当 TUOJ 系列站点返回 401 或 403 时，应用会自动利用统一认证会话重新漫游一次并重拉作业列表，解决此前已配置源在会话过期后需手动重连的问题：

| 约束 | 取值 |
|---|---|
| 重试间隔 | 同一源两次自动重连至少间隔 10 分钟 |
| 重试上限 | 单进程内每个源最多自动重试 3 次 |
| 并发合并 | 同一源同时触发的多个 401 请求共用同一次重连过程 |
| 登出保持 | 用户主动退出登录后保持登出状态，跳过自动重连 |
| 失败引导 | 自动重连仍未恢复时，在作业页顶部显示提示条并提供跳转设置页的重登按钮 |

**过夜老化与启动续期（R23）**：TUOJ 会话在隔夜过期后，部分接口可能返回 HTTP 200 但响应体实际为登录页 HTML（缺少预期 JSON 数据），客户端会同样将其识别为会话失效并触发恢复。同时，每次启动 OneTHU 时会对已启用统一认证的 TUOJ 源主动执行一次后台续期（记录标记 `tuojStartupRenewed`，豁免常规 24 小时缓存频控，同时遵循用户的主动退出状态），由 `tools/tuoj-r23-test.mjs` 回归验证。

DSA OJ 采用站点独立账密体系：当检测到会话过期（`user.php` 的 `checklogin` 返回未登录、业务 `error≠0` 或响应体非 JSON）时，系统抛出 `DsaSessionError`，由作业页提示条引导用户前往设置页重新输入邮箱与密码登录。

## 5. 新增作业源

1. **实现数据拉取**：在 `packages/core/src/exthw/` 下新建对应平台的客户端文件，返回 `ExternalHomework[]` 数组（提交与批改状态据实映射，无法确认时归为未提交），并在 `types.ts` 与 `index.ts` 中补充导出定义。
2. **注册源标识**：扩展 `ExtHwSourceId` 联合类型，在 `extHwSourceName()` 中添加中文展示名称，并在设置页按平台类型归入对应分组。
3. **接入凭据管理**：需要独立账号的平台接入 `ExtHwCreds` 结构并在设置页提供登录表单；接入清华统一认证的平台可直接复用漫游会话。独立账密站点（如 DSA OJ）可在 `login.ts` 中封装登录换取会话 Cookie 的工具函数，交由设置页持久化保存。
4. **编写回归测试**：在 `tools/exthw-status-test.mjs` 中基于本地模拟数据补充状态判定断言；支持真实凭据调试的平台可在 `tools/exthw-smoke.mjs` 中加入联调冒烟用例。
5. **同步更新文档**：在本文档 §2 表格中补充新源信息，并将该源特有的状态判定与会话恢复逻辑记录至 §3 和 §4。
