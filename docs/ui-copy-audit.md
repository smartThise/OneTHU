## 三、禁用词：「原子」（17 处，需你定名）

计划把「原子」列入用户可见文案的禁用词。它现在是收藏体系的核心名词，涉及 6 个文件：
FolderPage（6 处）、Collect（3 处）、WidgetBindModal（6 处）、WidgetSettingsSection（1 处）、FavAtomPicker（1 处）。

**待你定名**，我按你的选择一次性替换（数据层与 `FavAtom` 等标识符不动）：

- 方案 A「收藏项」：与「收藏夹」成对，最直白；
- 方案 B「收藏」：更短，但和收藏夹、收藏动作同名，句子容易绕；
- 方案 C「卡片」：和小组件说法统一，但丢掉了「可收藏的最小单位」之意。

我倾向方案 A。

## 四、落地方式

1. 词表扩展与上表全部改写**同一批**提交，中间不留红；
2. 行内豁免用 `// ui-copy-lint-ok: 理由` 写在对应行尾，理由必须写清「为什么用户看不到」或「旁边的动作在哪」；
3. 技术细节进「详情」折叠区需要组件支持——`FilePreview` 与信息聚合页已有折叠样式，先在已有折叠位的页面落地，没有折叠位的页面只做措辞改写；
4. 落地后在计划表里勾掉 §4.5，并在真机抽查 3 个页面（学习作业详情、信息聚合、收藏）。
