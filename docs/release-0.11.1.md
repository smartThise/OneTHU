# OneTHU 0.11.1 · Revolution 修复更新


[中文](release-0.11.1.md) · [English](en/release-0.11.1.md)

本次更新覆盖 macOS、Windows 与 Android 三端，恢复了二级选课课程的展示与日历同步，并集中优化了手机端的操作体验。

- 二级课表兼容学校中文与英文周次格式（含 `week 4`），恢复切换语言后遗漏的课程。
- 校历加载就绪后，时间轴自动补齐二级课程，首次进入页面即可完整查看。
- 月历列表纳入二级课表，课程日期、时段与详情均与时间轴保持一致。
- 二级课表刷新遇到网络异常时给出重试入口，其余已加载课程照常展示。
- 系统日历基于新版完整学期缓存同步经校验的一级与二级课程数据；若中途请求异常，已同步的日历内容保持不变。
- Android 版版本号为 0.11.1，versionCode 为 11009，沿用正式签名与上下结构 Logo。

安装新版后，在日程设置中点击刷新即可重新拉取课程。自动更新检测、GitHub 下载与清华云盘镜像已随本次发布同步上线。

工程验证与复跑入口见 [二级课表修复报告](reviews/2026-10-22-secondary-schedule.md)。

## 手机操作与布局

- 手机端支持在底部 OneShot 导航与左上角按钮展开的纵向导航浮层之间切换：极简模式展示五项核心入口，实用与完整模式展示全部一级功能区。三种模式各自记住导航偏好，实用与完整模式的导览中也支持直接选择布局。
- 进入白板编辑态时保留当前的缩放比例与布局位置，编辑入口更醒目，并新增「撤销上一步」与恢复默认布局二次确认。
- 暂存箱拖至屏幕边缘后自动吸附并半收起，轻点即可展开，拖回屏幕中央可自由停放；文件传输期间保持完整展开。
- Android 端 OH 悬浮窗的收起按钮换用更醒目的图标、文字与高对比度样式。
- 从个人名片或组织设置进入组织管理页时自动收起设置浮层，可直接操作目标页面与编辑表单。
- 检查更新过程配有加载文字与动画提示，支持主备更新源自动切换及超时、取消与重试，三种模式下均可直接使用。

移动端浏览器触摸验收详情见 [手机修复报告](reviews/2026-10-22-mobile-repair-round3.md)。

## 10 月 22 日安装包修订

组件预览已迁入独立的只读数据作用域，示例课程、作业与课件仅在预览面板内展示，全局搜索与后台刷新均读取当前登录账号的真实数据。三端安装包已同步合入此项修复。

已在早期安装 0.11.1 的用户建议重新下载安装包覆盖升级，本机用户数据会自动保留。由于客户端自动更新按版本号比对，相同版本号的修订包需手动下载覆盖；Android 版 versionCode 已更新至 11009。详见 [预览数据隔离报告](reviews/2026-10-22-preview-data-isolation.md)。
