# 日程、作业截止与同步


中文 · [English](en/schedule-and-sync.md)

## 时间轴与视图

日程视图汇总展示课程、自定义安排、考试与作业截止时间，提供列表与时间轴两种排版以适应不同信息密度，并支持日期切换与分类筛选。极简、实用与完整三种模式共用同一份合并后的作业截止数据源，各模式下展示的截止事项保持一致。

点击作业卡片上的「前往」可直接打开对应的作业详情标签页；点击课程条目则可前往网络学堂课程页，或在已知上课地点时调起校园寻迹。寻迹导航依托已收录的校内地点坐标与当前设备可用的地图服务运行；遇到尚未收录坐标的教室时，界面会如实展示原始地点文本。

## 作业状态

网络学堂、雨课堂与已接入 OJ 平台的作业在日程与列表中统一汇总。「已提交」与「已批改」状态同步自对应的教学平台接口；本地「忽略」操作用于在当前设备上折叠整理列表，正式提交仍以学校教学平台为准。关于附件上传、手动提交及题目详情的具体支持范围，请参阅 [作业区](homework.md) 和 [外部作业源](external-homework.md)。

## 日历与邮箱

| 能力 | 数据与认证 |
|---|---|
| 校内课程表 | 校园会话与学期信息 |
| 自定义安排 | 应用日程数据 |
| CalDAV / ICS | 相应日历服务与账号、授权码或订阅链接 |
| 邮件 | IMAP / SMTP 与邮箱账号、授权码 |
| 系统日历输出 | 系统权限与平台日历接口 |
| 系统通知 | 应用提醒规则与原生排程 |

日历同步、邮件同步与系统通知作为各自独立的通道分别配置和运行。当遇到网络离线、会话过期或服务端返回空响应时，应用会保留本地已有数据并等待下次正常连接；远端条目的增删变更严格按照对应同步协议的状态标记与冲突处理规则执行。

## 提醒与后台

应用会根据课程、考试、作业截止时间和自定义日程（含重复规则）自动生成本地提醒，并在设定的静默时段内延后或静音投递。在 Android 设备上，提醒准时送达依赖系统通知授权、精确闹钟权限及后台省电白名单设置；Windows、macOS 与 Android 各平台点击系统通知后的页面跳转行为说明详见 [系统架构](architecture.md)。

日程列表底部留有安全内边距，滚动到底部即可完整查看并点击末尾条目，避开底部固定工具栏与 OneShot 栏遮挡。相关布局与同步功能的阶段性测试记录可参阅 [日程布局](reviews/schedule-layout-2026-10-20/README.md)、[日历同步](reviews/2026-10-20-caldav-review.md) 与 [邮件同步](reviews/2026-10-20-mail-sync-acceptance.md)。
