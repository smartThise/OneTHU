# OneGUI 设计语言（0.11）

中文 · [English](en/design-language.md)

石墨是默认主题。视觉真源为 `packages/gui` 的令牌、组件与 recipes，设计说明见 [OneGUI 包说明](../packages/gui/README.md)。旧 MD3/各业务页局部样式不能作为新界面的第二套标准。

完整技术分层见 [OneGUI 架构](architecture/onegui.md)，覆盖实际令牌入口、兼容层、主题注入、玻璃预算、拖动和滚动边界。

## 组件与主题

优先使用 OneGUI 的 Button、Input、Segment、Modal、Sheet、列表和反馈组件。主题通过统一注入控制表面、内容色、选中态与语义色。选中态不能只靠低对比背景区分；深浅主题和 Windows/Android 字体回退都要检查。

材料与颜色是不同维度：玻璃在需要保留上下文的悬浮层、胶囊和面板使用，文字依赖对比调整。不能删除字体对比引擎，也不能在每个页面自行写黑底黑字的选中态。

## 布局与操作

页面留白由统一内容边界提供，从白板组件打开的标签页与其他入口保持一致。固定 OneShot 不覆盖滚动内容，白板缩放/编辑控件、刷新与暂存按钮避开底部操作区。自由拖动与目标投放需要分别提交，不得在收纳后再次移动源组件。

滚动 Segment 保留可操作的横向滚动指示条。列表、时间轴、模态和横屏均应验收到底部，不能以隐藏溢出解决布局冲突。

## 动效与导览

导览使用模拟数据的真实应用截图与录制，而非虚构界面。手机模型应有厚度、自然转场，单手机演示以竖屏构图填充主要区域；NFC 允许双设备演示。暂停、离屏、后台与减少动态效果时停止视频和帧调度。动效不能替代操作反馈或遮挡主要内容。

需要核对 [动效规范](动效设计规范.md)、[令牌入口](tokens-map.md)、[组件尺寸](白板组件尺寸档清单.md) 和实际浏览器结果。
