# 主题、材质与可编辑首页 · 2026-10-17


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../../README.md)（[English overview](../../en/index.md)）。


本轮在 `exp` 分支完成了用户反馈的六组改进：

- Segment 选中按钮自身同时承载底色与字色，原滑动底块仅用于过渡装饰，消除量测或切换瞬间的黑底黑字现象。两套 Segment 共享同一组动作色对，切换主题或开启壁纸动态取色时始终维持高对比度。
- 主题定义直通 OneGUI，统一注入面阶、三级文字、边框、字体、圆角与强调色；针对只定义了局部色值的主题自动补齐面阶并校准文字对比度。手动切换主题、昼夜自动调度、动态取色与恢复默认均汇总到同一套入口，切换时彻底清除上一套覆盖样式。默认主题显示名定为 **石墨**，底层存储继续兼容历史 `ivory` ID。
- 玻璃材质与配色方案解耦，作用于导航栏、独立卡片、浮层与工具条，而输入框、主操作按钮、Segment 与便笺默认保留实色背景。移除了原先按 `card` 类名与内联背景一刀切透明化的旧规则，消除白板内部的多重模糊叠加，并响应系统的「减少透明度」无障碍偏好。
- 默认首页固定为七大核心组件：时钟、大标题问候语、一级功能区、今日待办、今日课程、最新新闻与校园卡余额。独立待办页与首页「今日待办」共用同一套滑动卡片及筛选排序逻辑，完整保留提醒、忽略、收藏与详情入口。
- 画板组件支持即点即用与直接布局操作：**桌面端直接按住卡片本体拖动**（省去独立的“编辑布局”模式），选中后拖拽四角或右/下边缘即可缩放，同时支持方向键平移、`Shift + 方向键` 微调尺寸；手机端按阅读顺序纵向堆叠，点选卡片后可在浮条内执行上移、下移、增高或减高；开启锁定的固定组件保持原位不动。一并修复了调整把手偏移、右上/左下角仅单向缩放及浏览手势误触发拖拽的问题。
- 添加组件、缩放比例与画笔开关收纳在窗口底部的固定工具条中，通过 `body` portal 挂载，层级高于画布内容且低于弹窗浮层；手机端添加组件抽屉及其确认按钮均完整浮于底部导航栏之上。

## 既有数据迁移

`homeLayoutVersion: 2` 仅执行一次平滑迁移：将旧版固定的首页头部内容补充为画板组件，自动为原有卡片向下腾出顶部空间，并完整保留既有卡片的内容、属性、相对排布、折叠状态与锁定标记；迁移完成后若用户手动删除时钟等默认组件，刷新后保持删除结果。用户自建的 OnePage 保持独立，不受首页迁移影响。全新安装的首页直接启用七组件默认布局；老用户也可随时通过「模板 → 默认首页」主动替换当前首页布局（替换模板会清空当前画板上的既有组件，建议先保存所需内容）。
