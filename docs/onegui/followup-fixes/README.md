# 工作台五项反馈修复


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../../README.md)（[English overview](../../en/index.md)）。


2026-10-17，在 `exp` 分支继续修复用户反馈的五项工作台细节问题：

1. **竖直标签页收起时被裁切**：窄轨宽度保持 56px，而新工作台此前设置了左右各 12px 的内边距，导致 44px 图标槽空间不足。现改为 4px 水平边距并让主按钮占满剩余宽度，悬停展开前后图标位置保持稳定。
2. **左上角入口名称**：入口文案改为“标签页”，与点击后展开的面板功能保持一致，角标继续显示当前标签数量。
3. **二级 Segment 辨识度**：OneGUI Segment 与既有 SegmentedOverflow 统一共用轨道、边框、选中底色和文字语义角色。轨道具备清晰的灰阶与边界，选中项采用高对比黑白动作色对，在浅色与深色主题下分别解析；四种便笺纸色及其选中态也已纳入真实令牌对比度检查。
4. **研讨间重复选时**：点击房间时段后直接弹出标准确认窗并自动带入所选起止时间（开启空闲时段筛选时则带入完整筛选范围）。确认窗内精简掉重复的全天时间表，仅保留开始与结束时间微调，同时继续校验最短/最长时长、占用与过期约束。提交按钮固定在弹窗页脚，预约成功即刻给出提示，报错或首次绑定邮箱后的重试均留在当前确认窗内完成；一并修复了时间下拉菜单 portal 层级低于 OneGUI Modal 导致无法点选的问题。针对多人研讨间，移除了前端原有的单方禁用限制，改为展示人数要求并交由图书馆服务端校验返回具体提示。
5. **便笺底色与即时保存**：此前保存逻辑写入外层 `BoardItem.props`，而渲染投影仅读取 `spec.props`。现统一将自定义组件更新写入规范的 `spec.props`，同时兼容读取旧版外层字段，让历史版本保存在本地的内容也能正常显示。便笺支持输入即保存，刷新前无需手动失焦；整张卡片采用不透明纸色（默认纸黄），深色主题下同样保持深色墨迹，纸色定义统一收敛至 Reference/Semantic 令牌。
