# OneGUI Workbench · 第二轮验收


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../../README.md)（[English overview](../../en/index.md)）。

2026-10-17，`exp` 分支基于首轮 `c1035198` 继续推进。收到首轮视觉变化不明显的反馈后，本轮围绕真实页面结构、完整视觉层级与实际可用交互展开重做与验收。

## 整页变化

- 首页：工作台页头与右侧时间、整行服务导航、白板工具栏按文档流组织；自由画布和笔迹沿用原有数据，用户已排好的布局保持原位。
- 新安装：默认白板采用清晰易读的三列卡片排布，告别此前全部挤作一列 90/286 像素窄卡的布局；旧布局迁移继续走原有通道，纯模型测试同时覆盖新旧两种路径。
- 导航：统一命令栏、活动标签与 OneGO 主要动作，横/竖标签模式及手机上下导航均可正常切换使用。
- 设置：桌面端采用中央窗口与左栏目右内容布局，手机端采用全屏与单行横滑栏目；去掉重复的一级导航，支持方向键与 Home/End 切换栏目。
- 服务管理与功能目录：统一接入标准 OneGUI Modal，对齐标题、关闭、焦点、Escape 与退场交互，同时完整保留用户的服务顺序、增删操作、插件目录和透明度设置。
- 组件：更新标题与展示字号、控件密度、卡片圆角和表面层级；可点击 Chip 改用原生按钮，可删除 Chip 拆分为两个同级按钮以避免按钮嵌套。

## 令牌与样式归属

`gui.css` 按 Reference → Structure → Semantic → Material → Components 分层组织。
`onethu.css` 负责引入承担存量别名适配的 `compatibility.css` 与负责当前工作台排版的 `workbench.css`。颜色字面值集中在 Reference 层，产品几何尺寸集中在 Structure 层，组件层统一引用语义角色。

| 语义 | 当前规则 |
|---|---|
| 环境 / 内容 / 输入 / 浮层 | canvas / paper / well / overlay 四层 |
| 页面标题 / 标题 / 正文 | 36 / 24 / 14；工作台主标题 44，手机 28 |
| 主要控件 | compact 36、comfortable 40、touch 44 |
| 内容曲率 | card 24、control 14、menu 14；胶囊用于标签 |
| 桌面页头与导航 | 命令栏 60、标签栏 44；手机顶部 52 |
| 主要动作 / 用户主题 | action 黑白对独立于 accent，仍支持原主题和玻璃档位 |

本轮清理了 68 条过期的宿主样式声明及配套空规则与旧注释，旧 CSS 从 9959 行缩减至 9811 行，应用内裸控件从 257 处降至 245 处；其余存量页面的控件迁移将在后续迭代中继续推进。

## 验证

- 桌面端 typecheck 与 production build 通过（构建阶段仍保留既有的大包体积与混合导入提示）。
- OneGUI 九项规则、28 组真实令牌对比度、scope 继承与主题往返切换检查通过；令牌、CSS 解析与对比度护栏全部绿灯。
- Board model、13 个旧键迁移场景与防重叠不变量测试通过，并补充了默认三列排布与旧布局保护检查。
- `visual-report.json`：覆盖 11 个亮/暗、桌面/手机、设置/搜索/菜单/画廊场景，运行异常与文档横向溢出均为零。
- `interaction-report.json`：覆盖真实鼠标拖动 60×40、持久化重载、键盘开启服务弹窗、入口增删、Escape 关闭、设置栏目切换、搜索直达与手机末尾栏目触达。
- `additional-report.json`：覆盖竖标签栏及键盘 Home/End 栏目切换操作。
- 手机首页与设置 390×844@3：横向溢出、文字截断与文字互压均为零；存量天气卡片中的“刚刚”按钮仍保持原有紧凑触控尺寸。
- 像素审计：首页亮色和搜索暗色均满足 AA 对比度标准。设置审计在滚动视口底边出现一处取样边界偏差：被面板下沿裁切的长说明在采样背景时落到了面板外的遮罩层；经人工复核截图（见 `settings-contrast.png`），文字实际渲染在白色卡片底上，清晰可读。
- 全量 `pnpm guard` 运行至 8 处既有的文案检查项时中止，其余已跑完的子项均正常通过。

本轮聚焦桌面与手机预览环境下的工作台结构改造，截图中的课程与作业空态、骨架屏均为预览环境未连接校园账号时的真实渲染状态；登录后的全量业务子页、原生移动端与语音性能留待后续实机回归。
