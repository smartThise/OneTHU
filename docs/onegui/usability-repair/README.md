# 首页 / 白板 / 玻璃 / OH 可用性修复 · 2026-10-17


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../../README.md)（[English overview](../../en/index.md)）。


本轮在 `exp` 分支既有未提交改动（已完成 8 项可用性修复代码并通过 32 条浏览器断言，尚待整理提交与验收记录）的基础上继续推进：补齐用户新反馈的选中失焦与首页标题板玻璃材质两处细节，同时按最新交互设计移除独立的「编辑布局」模式，并将画布右键菜单与底部「＋」号统一为同一个组件选择器。

## 一、基础 8 项可用性修复

1. **首页标题**：白板页头文案由 `我的白板` 更新为 `首页`。
2. **100% 适配窗口宽度**：100% 定义为“适配当前窗口宽度”的基准视图，并与用户手动缩放比例（`view.z`）解耦。设计基准宽度按画板记录一次，拖动、拉伸、落点计算与画笔绘制统一使用真实显示倍率 `displayScale`，既保持底层持久化坐标分毫未动，又确保拖动过程中视图基准稳定。
3. **滚轮顺畅传递**：首页滑动待办卡片释放普通纵向滚轮事件（设置 `HwCarousel captureWheel={false}`，独立待办页继续保留滚轮翻卡）；画布面板恢复 `overscroll-behavior: auto`，滚至内容底部后自然交还外层页面滚动。
4. **直接拖动与缩放**：桌面端直接按住组件非交互区域即可拖动（4px 启动阈值），选中后拖拽四角手柄即可调整大小，省去先进入编辑模式的步骤。`worldDelta` 改按真实显示倍率换算，并配合指针捕获保证鼠标或触屏滑出卡片边界时手势依然连贯。
5. **精简设置说明**：移除外观设置中的冗余提示语「想昼夜自动切换就打开上面的开关；单独换主题点上面的『主题』。」
6. **玻璃透光与文字对比度**：材质档位恢复经典透光参数（`clear` 30% / `rich` 60% / `deep` 74%，叠加 20–22px 模糊与饱和度提升），补充高光描边与材质阴影，深色模式下单独压暗底色，实现配色与材质解耦。文本对比度引擎补齐 `color(srgb …)`、百分比色值与 `#rgba` 解析，确保 Segment 与实底按钮字色准确，并将 `data-og-skin*` 与 `data-dynamic` 纳入自动重算监听。
7. **OH 专属按钮按需展示**：创造模式、新会话、历史记录、导入导出与语音朗读按钮仅在 `mode === "oh"` 时展示；「收起」按钮在各模式下常驻。
8. **OH 胶囊按压回弹**：恢复指针按下时的 `scale(.97)` 与松手回弹动画（360ms），键盘 `Enter` / `Space` 触发相同反馈；输入框与语音按钮区域独立响应以防误触，开启系统减少动态效果时自动关闭缩放动画。

## 二、补充修复的两处视觉与交互细节

- **点空白与操作控件自动取消选中**：此前仅点击画布自身空白处才会清除卡片选中态，点击页面顶栏、世界层外围空白或卡片内部按钮时选中框常驻不退。现通过文档级 capture 监听统一收口：点击画布空白（含世界层）、页面其他区域或组件内的按钮/输入框/链接时均自动清除选中态；操作选中浮条与缩放把手时保持当前选中，点击另一张卡片则直接切换选中目标。
- **首页标题板接入玻璃材质**：壁纸模式下 `.workbench-board-head` 原先固定使用不透明白色的 `--og-menu-fill`（实测 `rgb(255,255,255)`、`backdrop-filter:none`）。现改为在玻璃皮肤下接入 `--og-fill-surface` 与 `--og-surface-blur`，与顶栏及画板卡片呈现一致的通透毛玻璃质感。

## 三、移除独立「编辑布局」模式

画板交互统一升级为“所见即所得直接操作”：

- 移除卡片上的独立拖拽把手（`free-drag-handle`）、页头「编辑布局 / 完成布局」按钮、底部工具栏「编辑布局」按钮，以及相关的引导文案与 `is-layout-editing` 样式。
- 桌面端：直接拖动卡片本体移动位置，选中后拖拽角点调整尺寸，支持方向键平移与 `Shift+方向键` 调整大小；删除、固定、置顶与折叠收纳在选中浮条内。
- 手机竖屏：继续按阅读顺序纵向堆叠；**点按卡片选中**后，可通过浮条执行上移、下移、增高或减高（堆叠布局由阅读顺序自动投影生成，省去自由拖拽与拉角手柄）。
- 自建 OnePage 与首页共用同一块画布引擎与同一套交互手势。

## 四、右键菜单与「＋」统一组件选择器

- 画布空白处右键与底部工具栏「添加组件」现统一打开同一个 `BoardAddDrawer`：提供双列缩略图预览、支持按标题 / `id` / 说明实时检索的搜索框，以及同屏展示的文件夹与 OnePage 钉板入口。通过右键唤起时会记录点击坐标并将新组件落在该位置；点击底部「＋」号则将新组件排在现有内容下方。
- 每次打开选择器时自动将预览网格复位至顶部，修正此前预览卡片内「网络学堂搜索」组件的 `autoFocus` 输入框在挂载瞬间拉偏滚动条位置的问题。
- 一并修复了根目录 `pnpm build` 的既有构建脚本问题：`packages/gui` 中 `echo nothing to build (source-only package)` 缺少引号导致 `sh` 报语法错误（`dev3` 分支同样存在该问题），补齐引号后全仓生产构建恢复畅通。

## 九、便笺跟随玻璃材质（2026-10-17 23:41）

此前便笺曾通过 `:not(.is-note)` 被玻璃皮肤单独排除，始终保持不透光实底。现已将便笺纸色一并纳入玻璃材质体系：

- 玻璃皮肤下 `.free-item.is-note` 的底色计算为 `color-mix(in srgb, var(--og-note-paper) var(--og-note-opacity), transparent)`，其中 `--og-note-opacity` 跟随当前材质档位（亮色下 `clear` 30% / `rich` 60% / `deep` 74%，深色 `data-og-scheme=dark` 下取 6% / 14% / 20%），同步叠加 `backdrop-filter: var(--og-note-blur)`（与普通卡片同档模糊及饱和度）和材质阴影；内层 `.free-note` 设为透明背景，消除双重底色叠加。
- 四种便笺纸色（黄 / 粉 / 蓝 / 绿）在玻璃模式下呈现为通透的彩色毛玻璃，默认实色皮肤下则继续保持传统实色纸张质感。
- 开启系统 `prefers-reduced-transparency: reduce` 时，便笺自动回退为 100% 不透明实色纸并关闭背景模糊（`--og-note-opacity: 100%`）。
- 便笺正文与按钮图标继续由 `textContrast` 引擎按实际合成底色自动选取高对比墨色：亮色背景下呈现深色墨迹，深色主题下自动转为亮白字色（实测深色模式下文字色值为 `rgba(255,255,255,.95)`）。
- 回归测试：`usability-browser-test` 新增 2 条断言（双击画布空白新建便笺、验证玻璃皮肤下便笺透明度对齐材质档位且内层透明），总断言数更新为 52 条。
