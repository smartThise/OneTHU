# OneGUI exp · 中性工作台视觉体系


> 归档说明：本文记录 `exp` 分支的中性工作台视觉设计与阶段性验收情况；0.11 当前功能与使用说明请查阅 [文档入口](../README.md)（[English overview](../en/index.md)）。


`exp` 分支于 2026-10-17 基于本地 dev3 `90eec5b2` 创建。本轮在完整保留 OneTHU 原有界面结构的基础上，引入清爽克制的中性工作台视觉风格（参考 ChatGPT / Codex 桌面工作台的设计取向）。

## 设计边界

完整保留首页自由画布、程序坞、标签页、工作空间、OH、OneGO、设置抽屉、收藏落点、手机导航、路由及数据接口。视觉层面采用纯白与石墨灰基调、清晰的字号层级、柔和的明暗面差、细腻的可见描边、收敛的阴影与圆润的输入区域。主要操作采用高对比度的黑白配对，业务状态色与用户强调色继续承担原有语义。

## 唯一来源

| 层 | 文件 | 职责 |
|---|---|---|
| Reference | `packages/gui/src/tokens/reference.css` | 唯一的颜色与投影字面值 |
| Semantic | `tokens/semantic.css` | 明暗面阶、内容、边界、动作、状态、产品角色 |
| Structure | `tokens/structure.css` | 间距、字阶、圆角、控件、密度、动效、安全区与层级 |
| Material | `skins/neutral.css`、`skins/glass.css` | 同一角色的材质；四档玻璃由 opacity 公式推导 |
| Components | `styles/` 与 `components/` | 按钮、输入、卡、列表、菜单、分段和浮层 |
| Host recipe | `recipes/onethu.css` | OneTHU 壳层、程序坞、OH 入口、设置、菜单与兼容别名 |

宿主端统一导入 `gui.css` + `onethu.css`。原应用侧的 `styles/onegui-bridge.css` 已移除，兼容职责并入组件库内部：旧令牌名仅作为指向新语义令牌的别名映射，应用侧残余样式则专注于结构布局、定位、滚动与响应式行为。

## 核心角色

| 角色 | 使用范围 |
|---|---|
| `--og-action / --og-action-on` | 主要操作、发送、确认；随明暗模式切换，保持独立于用户主题色 |
| `--og-accent-*` | 用户强调色、链接、状态与部分选中标识 |
| `--og-content-1/2/3` | 主文、说明、弱文；亮暗面上均验证可读性 |
| `--og-line-1/2/3` | 分隔、输入边界、聚焦强边界 |
| `--og-canvas / --og-chrome` | 工作区与持久导航框架 |
| `--og-card-fill / --og-menu-fill` | 卡片与不透明浮层基色 |
| `--og-fill-surface / --og-fill-overlay` | 可选材质的最终合成面 |
| `--og-input-fill / --og-composer-fill` | 输入控件与 OH/用户消息写入面 |
| `--og-selection-fill / --og-selection-ink` | 中性导航和选中状态 |
| `--og-contrast-ink-light/dark` | 壁纸对比度引擎的修复墨色 |

密度档延续 `compact` / `comfortable` / `touch` 三档：手机控件主高度为 44px，小控件及胶囊（Chip）为 40px；桌面 `compact` 档主高度为 32px。主题、壁纸、本地存储与六轴控制入口均沿用既有通道。

## 本轮清理与修复

- 清理宿主内 309 条冲突的外观声明，集中管理壳层、标签页、抽屉、程序坞、画布卡片、OH 与存量控件。
- 将 OneGUI 全部样式层中的颜色字面值收归 `tokens/reference.css`，并新增 R9 单源护栏，确保皮肤材质层同样遵循令牌引用。
- 拆分主要操作色与主题强调色；切回默认外观时会自动清除 `accent`、`selected`、`inverse`、`ring` 等运行时派生值。
- 优化 `scope` 同名角色映射为直接继承根级值，跳过自引用 CSS 变量生成，修复导览等浮层曾出现的底色与文字显色异常。
- 收敛输入控件的键盘焦点绘制，统一由外框呈现焦点环，输入框本体省去重复焦点描边；OH 胶囊在 `focus-within` 状态下显示外环。
- OH 用户消息改用中性写入面，回复区去掉玻璃气泡底框，正文区域保持清爽底色。
- 预览取景框接入 OneGUI 按钮、选择器和材质令牌，设备边框独立于 `iframe` 之外以保留完整真实视口；开发面板控件一并完成接入。
- 开发白板的 250% 自动缩放探针改为通过 `?board-zoom-selftest=1` 显式触发，常规预览时保持原始视图比例。
- 补齐构建时发现的 `global.css` 孤立注释起始标记，并将 CSS 语法结构检查扩展至整个 `gui` 包。

## 验证

本轮已运行并通过 `pnpm guard:onegui`、桌面端 typecheck/build，以及令牌、CSS 结构与对比度护栏。新增的 `system-test` 覆盖了真实 `StyleDirector` 主题切换与还原、`scope` 继承、`action` 与 `accent` 通道隔离，并直接读取当前 CSS 校验了 28 组语义色对比度（含半透明状态面的叠加合成）。

浏览器截图与分场景报告归档在 `docs/onegui/exp/`。本轮验证聚焦于桌面与移动端浏览器视口下的界面表现；涉及真实校园账号登录后的在线接口、原生语音链路及移动设备真机性能，留待后续真机集成阶段专项回归。

## 迁移余量

应用侧存量旧样式与裸控件仍在分批推进迁移。当前棘轮基线记录为：旧样式 9959 行、外观内联 278 处、字面色 322 处、裸控件 257 处、旧 UI 类名 81 处；基线保持单向下调。本轮引入宿主配方旨在先行统一全局壳层与公共观感，图表数据色、文档正文、第三方内容视口以及其余存量页面的组件化改造将在后续批次逐页完成。

全局 `pnpm guard` 当时仍保留上一代视觉断言与产品文案检查，过渡期内与 OneGUI 专项护栏分开记录并各自跟进。

## 第二轮 Workbench（2026-10-17，取代首轮页面构图）

结合首轮整页变化幅度偏小的体验反馈，第二轮重做了首页、服务目录、设置窗口与手机排版：`onethu.css` 升级为宿主总入口，`compatibility.css` 负责存量映射，`workbench.css` 负责产品构图。

控件尺度同步调整：桌面 `compact` 主控件高度由 32 调为 36，`comfortable` 为 40，`touch` 为 44；字阶 `display`/`title` 设为 36/24，卡片圆角统一为 24。首页页头并入常规文档流，下方的自由画布继续沿用原有坐标系，老用户的既有卡片数据无需重排即可平滑保留。新安装的默认三列布局与旧布局迁移均已补充独立测试。

最新验收记录与截图见 [Workbench 验收](workbench/README.md)；涉及控件尺度与迁移计数时，以本节及该验收记录为准。
