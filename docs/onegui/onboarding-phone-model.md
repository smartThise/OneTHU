## 保持不变的行为

- 真实应用截图直接作为纹理贴图，免重绘、免拉伸；UV 覆盖整张原图，按 `contain` 取最大显示面积。
- 截图圆角通过几何遮罩裁切，与物理屏幕圆角对齐，四角外侧像素自动隐去。
- 前摄窄缝避开应用界面控件，节点名称保持 `<设备名>-front-camera`，供既有测试脚本查询。
- 所有几何体、材质与纹理统一登记在装配体资源集合中，调用 `dispose()` 时各释放一次；视频分支完整保留首帧/末帧与暂停状态语义。
- 舞台姿态编排保持兼容，NFC 双机、白板与卡片场景继续沿用原有的 `applyPose`。

## 回归入口

```bash
# 机模几何 + 真实 Vite 模块集成（145 项）
ONETHU_BASE_URL=http://127.0.0.1:5180 \

node tools/onboarding-phone-model-test.mjs

CHROME_BIN=/path/to/chrome-headless-shell \
ONETHU_TEST_URL=http://127.0.0.1:5180 \
node tools/onboarding-real-screens-test.mjs

# 导览视口：8 种窗口尺寸 × 15 个阶段，含机模投影检查
ONETHU_PLAYWRIGHT_PATH=/path/to/playwright/index.mjs \
node tools/onboarding-viewport-browser-test.mjs
```

设置 `ONETHU_PHONE_MODEL_UNIT_ONLY=1` 时可单独运行纯几何断言（输出报告会注明已跳过浏览器集成环节）；运行完整浏览器测试前需先启动本地 Vite 服务并通过 `ONETHU_TEST_URL` 传入地址。

## 建模取舍与测试说明

- 机模姿态随课程脚本编排变化，静止画面以正面屏幕展示为主，背部三摄与机身细节在 NFC 双机翻转过程中呈现。
- 机身省去了天线注塑条、法规铭文与背部品牌标志，让视觉焦点集中在真实应用画面上。
- 相机凸台、侧边按键与闪光灯的局部排布参照官方外观图片做视觉还原（官方公开参数仅涵盖机身整体长宽高与左上角三摄布局）。
- 当前自动化回归基于 Chromium 渲染验证，Windows 端 Tauri WebView2 的原生宿主渲染表现可在桌面打包环境中进一步核验。
