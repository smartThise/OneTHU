# 三模式导览：真实 3D 与流程验收


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../../README.md)（[English overview](../../en/index.md)）。


日期：2026-10-20。分支：`exp`。实现起点：`98eb32f0`。

## 交付内容

导览舞台全面采用真实的 Three.js 三维模型、相机与材质体系，替换了早期的粒子与 CSS 旋转方案；CSS 模型现专门作为缺少图形硬件加速或三维模块加载失败时的降级保障。舞台完整继承应用现有的主题与自动文字对比度引擎，并通过 OneGUI 的媒体材质角色与配方统一接入。

- 手机机模具备独立的金属边框、圆角玻璃、后盖、镜头模组与侧边按键，银色与石墨色两台设备可从侧背面流畅翻转至正面。
- 白板卡片呈立体分层排布；暂存箱带有实体箱壁与铰链结构，卡片沿空间轨迹滑入收纳；口令与组织场景采用具有物理厚度的卡片完成翻转、展开与收拢。
- 运动系统采用带速度状态的阻尼物理曲线，支持中途平滑反向；切换章节时新旧模型连续交接，高频连续切换时同屏最多保留三个过渡模型，即时响应当前目标而无需排队播放历史动作。
- 模型到达终态后自动停止逐帧重绘；针对手动暂停、系统减少动态效果、滚出视口、页面隐藏、WebGL 上下文丢失与组件卸载分别实现了生命周期管理与显式资源释放。
- 三维引擎与场景代码按需动态加载：生产构建产出的独立场景包约 591 kB（gzip 后 153 kB），主应用首屏无需预加载该分包（构建阶段仍会输出大于 500 kB 的常规分包体积提示）。

## 三种模式与真实操作

极简模式精简为两课：今天、五个入口。实用模式包含三课：今天、更多功能、替换四个常用入口。完整模式聚焦五节核心课：白板、暂存箱、口令、碰一碰、组织，其余六个进阶主题收纳在完成页的「继续探索」中。

导览演示仅变更沙盒内部状态，点击课程中的操作按钮则直接进入真实应用功能，完整模式原有的十一处功能落点全部保留。实操体验期间，顶部返回条纳入当前弹层的焦点循环并支持键盘一键返回；退出体验时仅清理本次练习打开的弹层，同时等待进行中的异步操作安全结束。切换体验模式时，用户原有的白板布局、已开标签页与个性化设置均完整保留。

以上动效验收结果统一汇总至 [完整动效报告](report.json)，累计包含 902 项检查与 180 条几何测量记录，覆盖 1280×860、390×844、320×568 与 844×390 四种视口。报告按来源分列检查项、真实矩阵、像素采样、录像文件与性能数据（计入统计的七组正式运行均正常退出并返回 0，排除了早期迭代过程中的重复运行记录）：`sourceRuns` 汇总各子套件计数，`objectMotion`、`introMotion` 与 `nfcVisibleTextures` 分别保存翻转轨迹、开场运镜与接收状态纹理记录；`before/` 保存改造前基线，`after/`、`frames/` 与 `recordings/` 保存最终三维版本的实测产物。

最终源码在本机空闲环境下完成了 4 倍 CPU 节流参考采样：2.4 秒内采集 144 个 RAF 帧间隔，p50/p95 约为 16.7 ms，最大间隔 16.8 ms，全程无 Long Task（原始采样数据保存在完整报告的 `samples` 字段，供桌面降速基线参考；移动端实际帧率以真机测试为准）。

## 测试环境说明

本轮手机端画面基于 Chromium 移动视口与触摸模拟采集，导览中的 NFC 与组织场景用于演示操作流程与界面反馈；移动真机渲染性能、双机 NFC 硬件互传与跨账号组织权限同步需通过实机与多账号环境验证。所有录像均按原始时间间隔直接保存浏览器实际合成帧（未做插值补帧，录制过程本身包含采集开销）：桌面录像完整呈现 1280×860 视口；手机原始合成帧宽为 500 像素，后处理仅裁去 390×844 CSS 视口右侧的 110 像素空白窗口区域，应用画面完整保留，原始尺寸与裁剪坐标均已记入报告。

环境排查记录：安装新依赖后，旧 Vite 进程一度未能返回新版客户端脚本；重启后首次访问自动发现了新增的 `aes-js` 依赖，在禁用热更新的测试模式下曾短暂出现新旧 React 预构建包混用。待预构建缓存稳定后，上述全部自动化验收均在全新的隔离页面中顺利跑通。此外，独立的一次性截图辅助脚本在关闭浏览器阶段曾出现超时，该脚本仅用于辅助人工审图，自动化验收统计均来自上方正常退出的正式套件。
