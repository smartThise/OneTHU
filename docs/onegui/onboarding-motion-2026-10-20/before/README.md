版式走查记录的问题：

- 320×568 下模式选择页首屏仅露出极简模式卡片，其余两种模式需在容器内滚动后才能看到，难以同屏直观对比。
- 844×390 下进入完整模式第一课时，正文容器沿用了上一屏的滚动偏移，标题与进度条滚出画面上方，首屏直接从配图开始，难以分辨当前所处章节。
- 390×844 下完整模式第一课的多行标题、说明文字、静态示意图与三段步骤占满整个弹窗，舞台区域缺少可交互控件。
- 完整模式的 11 节课程平铺为单一长链路，白板、暂存箱、口令、NFC、组织等核心特性与其他辅助功能混合排列，缺少“先掌握核心操作、再按需探索”的层次。
- 抽样检查的各模式第一课舞台均由静态 `span/div` 构成，12 个样本中均无交互按钮或运行中的动画，详见 [report.json](report.json)。

本组基线采样范围聚焦开场页与各模式第一课（旧版后续章节如 NFC 课仍带有独立的脉冲动效）。浏览器进程正常退出并完成清理，运行日志保存在 `/tmp/onethu-onboarding-before.log`。
