# THUBook 目录解析修复 · 2026-10-17


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../../README.md)（[English overview](../../en/index.md)）。


问题根因：用户反馈目录中出现大量重复标题且层级扁平。排查发现旧实现逐个抓取各分组页的**整站侧边栏**并合并进对应分组——由于 VuePress 会在每个子页渲染完整的全站侧边栏，按组合并后相当于把全站所有页面重复塞入每个分组，导致标题成倍重复、层级丢失。

## 目录数据源

首页 `https://thubook.help/thubook/` 顶部的 **navbar 下拉菜单**已完整包含全站两级目录结构：

- 根级页面：🍺THU手册 / 📕新生词典 / 😀新生指南 / ❓新生常见问题 / 😋校园技巧 / ☎️常用电话 / 🌐常用网址 / 🍀公众号收录 / ✌🏽️我的THU / 🎓毕业生故事 / 📜更新日志（11 篇）
- 分组：**专题**（33 篇）、**校内生活设施**（18 篇）、**老乡在清华**（1 篇）、**其他**（2 篇）

单次请求首页即可获取全部 65 篇文档的完整目录，层级、排序与标题均直接对齐源站。

## 解析规则（`apps/desktop/src/lib/thubookToc.ts`）

- navbar 优先解析：直属 `a.nav-link` 映射为根级页面；`.dropdown-wrapper` 映射为分组，`ul.nav-dropdown` 内的链接映射为组内页面。
- 路径规范化：依次执行 URL 解码、去除 `.html` 后缀、去除 hash 锚点与尾部斜杠，并仅保留 `/thubook` 站内路径（自动过滤「贡献内容」等外部链接）。
- 全局路径去重：按规范化后的路径去重，同一篇文章若同时出现在根级与分组内，仅保留首次出现的位置。
- 降级兜底：当源站未检出 navbar 结构时回退至单页侧边栏解析，避免逐页抓取合并带来的重复污染。
- 回归防护：新增专门用例验证回退到侧边栏解析时，全站公共链接不会混入子分组。

## 页面变化

- 目录呈现清晰的两级结构：根级页面列表 + 带分隔线的分组标题 + 缩进展示的组内页面。
- 顶部搜索框支持跨两级实时过滤：命中分组名称时展开整组，无匹配项时提示“无匹配”。
- 页头元信息直接展示总篇数（`清华手册 · thubook.help · 65 篇`）。
- 正文翻页跳转统一经过 `normalizeThubookPath` 规范化处理，消除此前因 `.html` 后缀、中文 URL 编码或 hash 差异产生的重复缓存键。
