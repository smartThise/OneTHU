# 截断与遮挡修复


> 归档说明：本文记录当时的设计方案与阶段性验收情况；0.11 当前功能与使用指南请查阅 [文档入口](../../README.md)（[English overview](../../en/index.md)）。


2026-10-17，基于 `exp` 分支的工作台界面集中修复一批截断与遮挡问题。

## 修复范围

- **待办下半页可达性**：移除旧版的一屏高度锁定与外层溢出隐藏。此前 900×600 下标签面板高 384、正文高 428，844×390 横屏下面板高 234、正文高 442，底部内容缺少滚动入口；现在长页面随文档自然延展，同时保留桌面双栏布局。
- **后台标签隔离**：移除会匹配已隐藏但仍挂载待办页的旧 `:has(.tasks-body)` 高度约束。各标签页独立记录窗口滚动位置，切回首页时恢复首页自身的滚动位置。
- **首页滚动与高度测量**：移除画布面板的第二重整屏限高。画布测量直接读取窗口可用高度，隐藏标签保留上次有效尺寸，避免 ResizeObserver 将自身高度反复反馈进画布尺寸。
- **OH 页头排布**：模式选择与操作按钮拆为两行，窄屏下允许操作区自动换行；搜索路径完整折行展示，结果列表在自身容器内独立滚动。
- **OH 高度、旋转与软键盘适配**：结合真实导航栏位置与 VisualViewport 计算可用高度，已保存的超高值与拖拽高度均限制在可用空间内，并实时监听 VisualViewport 的缩放与位移事件。
- **设置与插件页自适应**：页头操作区在空间紧张时自动换行；设置行控件支持折行，说明文字取消两行截断；插件与 OH 内容区补齐统一边距，移除重复的三段导航。
- **手机页面标题恢复**：工作台顶栏改为展示 OneTHU 品牌标识后，恢复了手机端正文区域的页内标题（旧逻辑曾默认顶栏已显示页面标题而将其隐藏）。
- **横屏抽屉可用高度**：半屏档同时保障最小可用高度以留出正文阅读区；全屏档严格贴合屏幕范围，修复手机端入场时向上弹跳超出屏幕的问题，并将「完成」按钮独立靠右放置。
- **边角菜单与浮钮避让**：标签页右键菜单按实际尺寸限制在视口范围内；画布浮钮为刷新与回到顶部按钮留出空间；首页标签改用适配图标槽尺寸的小房子图标。
- **画笔层边界收敛**：画笔为空且处于关闭状态时收起占位，消除原先 2400px 的隐形溢出；已有笔迹或开启画笔时，父画布完整包裹画笔区域并保持固定的 2400px 高度，缩放或增删卡片时笔迹归一化坐标保持稳定。

既有白板卡片坐标与笔迹存储格式保持兼容不变。

## 验证

真实浏览器回归脚本：`node tools/layout-browser-test.mjs`（需先启动 Vite，依赖 Playwright 与 Chrome），默认覆盖 1280×720、900×600、390×844、844×390、320×568 五档视口，逐一验证长页末尾可达、后台标签隔离、窗口与按钮边界、按钮互不遮挡、全部设置栏目、抽屉半屏/全屏切换、屏幕边角菜单，以及模拟软键盘弹出后的 VisualViewport 表现。画笔回归用例实际执行绘制一笔、缩放、关闭、清空，并比对持久化后的白板数据。

五档视口共 **223 条浏览器断言全部通过，0 运行时异常**，结果见 [report.json](report.json)。此外，OneGUI 专项检查、桌面端类型检查与构建、CSS 结构、分端布局以及白板模型/迁移/尺寸/拖动/不重叠检查均已通过。

基线核对记录：`modal-shell-test.mjs` 中的 5 项旧插件浮层选择器与接线检查、`tabstrip-layout-test.mjs` 中的 2 项旧 `.plg-tab` 检查，以及全量护栏里上一轮记录的 8 处文案待修项，在修改前的 HEAD 基线上均已存在，留待对应模块清理时一并更新。

浏览器回归基于未登录预览数据运行；接入真实校园服务的长列表、原生移动 WebView 与真机软键盘表现将在实机测试中进一步验证。
