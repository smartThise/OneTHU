## 暂存箱的使用

暂存箱是完整模式下的本机临时收纳空间。短按悬浮按钮可打开暂存面板管理条目，长按按钮本身则可调整停靠位置；当在页面中长按可收纳条目并开始拖动时，暂存箱周围才会亮起接收提示区，日常点击浏览时界面保持简洁。

下方动图基于虚构作业条目实录，完整经过长按提起、拖向目标、命中接收区与写入暂存箱的代码流程，并在展开面板后核对同一标题；画面中的圆形标记用于指示指针位置。

![模拟长按拖入暂存箱](assets/0.11/vault-drag.gif){ width="300" }

1. 在支持收纳的条目上长按，等待卡片提起。
2. 保持按住，拖向暂存箱按钮周围高亮显示的接收区。
3. 松手完成收纳，短按暂存箱即可查看结果；若拖向 OH 接收区，则会直接将条目发送给 OH 助手处理。

## 当前支持的拖动来源

| 来源 | 具体内容 |
|---|---|
| 白板 | 已接入的组件与卡片 |
| 标签与 OneGO! | 页面标签、工作区、收藏入口 |
| 搜索与收藏 | 功能结果、已注册对象、收藏项 |
| 网络学堂 | 作业、通知、文件条目与已接入的附件 |
| 日程 | 已接入的课程、作业截止、自定义日程条目 |
| 通讯录 | 个人名片与组织名片 |
| 文件与协作 | 云盘文件/目录、邮件、GitLab 项目、新闻及附件 |
| 个性化与扩展 | 已接入的主题、壁纸、插件条目与设置行 |

可拖入暂存箱的元素由界面中的 `data-vault-catch` 属性、`vaultCatch*` 构造器及兼容的 `data-ctx-atom` 标记显式声明；在桌面端如需快速收纳普通选中文本，可使用快捷键 `Ctrl/⌘+Shift+S`。收纳云端条目时默认保存轻量引用元数据，远端附件与完整文件正文会在实际预览或导出时按需拉取并缓存。

## 短口令与接收

短口令用于在联网环境下传递云端分享清单。发送方需先接入清华云盘并上传相应文件，接收方能否顺利读取取决于文件上传状态以及分享链接的公开或指定账号权限设置。应用内各处统一调用同一分享入口生成短口令，确保同一份内容生成的口令与权限配置保持一致。

**NFC 目前可用性不稳定，请尽量使用口令。** NFC 近场接力受设备型号、系统版本、原生构建配置与系统权限影响，需在支持的双机实体硬件上配合使用。此外，名片、组织与暂存箱内容专属于完整模式，接收方切换至完整模式后即可导入查看。

## 好友与组织

通讯录作为完整模式的一级模块，集中管理个人名片、好友关系与团队组织。创建组织时会自动绑定一张专属组织名片用于对外展示与分享。组织页面提供成员、共享文件、代码项目与公告管理；本地保存的组织索引用于快速渲染目录，实际成员角色与操作权限均由对应服务端实时鉴权。

多人协作同时串联清华 GitLab 代码仓与清华云盘共享目录，成员角色、云盘文件权限与代码项目权限分别向各自服务端核验。当受邀成员尚未确认邀请、尚未接入对应平台账号，或上游学校服务状态有待刷新时，界面会显示为「待处理」；好友动态与邀请状态通过客户端定时或手动刷新拉取更新。

## 多设备同步与冲突

登录同一清华云盘账号的多台设备通过私有目录 `OneTHU-Profile` 同步个人名片、好友索引与组织索引。每台设备写入各自的独立变更记录：互不冲突的字段与增删条目（删除操作通过墓碑标记记录）会自动合并；仅当多台设备同时修改同一字段，或出现一方修改、另一方删除的冲突时，界面才会弹出双版本对比卡片供手动择一保留，其余可合并字段仍正常保留。

为保障账号安全，登录凭据、第三方 API Key 及服务端权限缓存仅保存在各设备本地，与云端名片索引保持隔离。旧版本仅保存在本地的历史资料，需先在原设备上升级并执行一次同步上传后方可跨端共享。此外，个人资料同步目录 `OneTHU-Profile` 与 OH 助手专用的记忆库 `OH-Memory` 分目录独立存储、各司其职。

详细设计与阶段性验收记录请参阅 [个人资料同步记录](plans/2026-10-21-profile-cloud-sync.md) 与 [组织协作记录](plans/2026-10-20-organization-collaboration.md)。代码库内同时保留了面向双校园账号与 Win / Mac 实体设备的组织联调入口，便于在浏览器模拟测试之外开展跨端真机验证。
