# OneTHU 0.11.4-fix-1 · Revolution


[English](en/release-0.11.4-fix-1.md) · [安装包](https://github.com/smartThise/OneTHU/releases/tag/v0.11.4-fix-1) · [清华云盘](https://cloud.tsinghua.edu.cn/d/56f78a2a0b144a6ab737/)

本次修订完整保留 0.11.4 的 CLI、SDK、OH 与界面特性，集中修复 Windows 登录恢复、首页课程展示与触屏操作问题。

- **Windows 登录与后台**：修复常驻后台启动及会话文件权限问题；即使后台服务暂时未能拉起，桌面客户端仍可正常完成学校登录与本机会话恢复，并在后续会话移交时严格核对账号归属、退出状态与二次验证要求。
- **首页课程**：白板与简化模式统一合并一级、二级选课课表来源，清晰呈现读取加载、失败可重试与当日无课三种状态。
- **平板交互**：修复实用模式设置页底部滚动区域；触屏白板默认处于阅读状态，显式开启编辑后方可移动与缩放组件。
- **手机排版**：阅读布局自动收拢从桌面端同步过来的超高卡片高度，同时完整保留白板数据与自由画布尺寸。

三端安装版本号统一为 **0.11.4-fix-1**。Android ARM64 版 versionCode 为 **11014**，沿用原正式签名证书与 Logo；Windows 提供 NSIS EXE 安装包，macOS 提供 Apple Silicon DMG 镜像，CLI 与 SDK 独立包同步发布。

由于旧版 0.11.4 更新器仅按三段数字比较版本号，检测更新时可能会显示兼容编号 **0.11.5**；下载安装后的实际版本即为 **0.11.4-fix-1**，升级后新版更新器会按完整版本号判断，避免重复弹出提醒。

本次发布源码对应提交 `ec2b8b341aeeeba0bcb3e0870399211f02785dc9`（Windows 安装器打包工作流调整单独记录，产物构建仍基于该冻结标签检出）。详细验证情况见 [修复记录](reviews/2026-10-27-release-fix1.md)。
