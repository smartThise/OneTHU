# 安装与开始使用（0.11）


中文 · [English](en/getting-started.md)

## 安装与升级

最新安装包可在 [GitHub Releases](https://github.com/smartThise/OneTHU/releases/latest) 获取；[官网下载页](https://onethu.github.io/download.html) 也按操作系统整理了清华云盘直链、GitHub 备用下载以及对应的版本号与 SHA256 校验值。当前客户端的实际版本可在安装包文件名或应用内「我的 → 关于」中查看。

| 平台 | 安装与基础环境 |
|---|---|
| macOS | 按处理器架构选择对应的 DMG 镜像；本地参与开发构建需安装 Xcode 命令行工具 |
| Windows | 运行 EXE 安装程序；系统需具备可用的 WebView2 运行时 |
| Android | 安装当前发布的 APK（首次安装需授权该来源），通知与相册等系统权限均在实际使用对应功能时按需申请 |

正式版与开发者版采用不同的应用包名标识，可在同一台设备上并存安装。反馈问题时建议一并附上「关于」页中的构建提交信息，方便快速定位代码版本。在 Android 设备上直接覆盖升级需要新旧安装包签名一致；由于卸载应用会清除本机存储数据，更换不同签名的安装包前请先做好本地备份。

## 登录与设备身份

在登录表单顶部以及二次验证的方式选择页、验证码输入页上方，均可通过「语言 / Language」随时切换界面语言。切换语言会保留表单中已填写的内容并记住当前偏好；应用自身的提示信息会立即随所选语言更新，学校服务端返回的原始报错文本则按原文呈现。

请使用清华统一身份认证账号登录，并按学校提示完成微信、短信或动态口令验证。应用会在本机维护稳定的设备指纹以保持登录状态；邮箱、雨课堂、清华云盘、GitLab 与清小搭等专项服务则遵循各自的安全机制，在首次使用时按界面引导单独授权或换取访问票据即可。

每次发起主登录请求后会进入 20 秒冷却保护（刷新页面也会延续当前倒计时），而已进入验证码填写阶段的二次验证可正常提交。遇到学校接口限流、信任设备数量达上限或认证页面改版时，界面会给出针对性的操作提示；更多排查方法请参阅 [隐私与故障处理](privacy-and-troubleshooting.md)。

## 选择语言和模式

首次打开的新手导览会先展示中英双语权限说明：清华云盘与 OH 助手默认处于关闭状态，可按需手动开启授权（启用完整模式需先授权清华云盘）。随后选择界面语言，后续导览便会加载对应的语言词典；日后也可在设置中随时切换语言或重新打开导览。0.11 提供极简、实用、完整三种使用模式，切换模式仅改变界面布局与可见功能范围，完整模式下的白板排版、个人名片及本机配置均会妥善保留，详见 [使用模式](experience-modes.md)。

三种模式的导览都会介绍全局搜索、OneTHU Harness（OH）以及插件生态概览；选择完整模式后，导览还会进一步演示自由白板、暂存箱、短口令、NFC、组织协作与清小搭。导览全程支持跳过、返回上一步或重播；点击页面中的体验按钮可直接打开真实功能试用，完成后点「继续导览」即可回到刚才的步骤。

## 日常入口

- 搜索胶囊：快速检索当前模式下开放的功能与校园内容，一键切换即可进入 OH 对话。
- OneShot：固定在底部的学习、预约、生活、信息、课表五大核心入口，支持按当前模式规则自定义编排。
- 首页：极简模式聚焦今日待办与即将开始的课程；实用模式在此基础上展开常用功能目录；完整模式则提供可自由拼装的白板画布。
- 我的：汇总当前模式下的常用设置，完整模式下还包含个人名片、插件管理等扩展入口。
- 强制刷新：按住悬浮按钮拖动可调整停靠位置，短按即重新拉取最新数据（各业务页面内的刷新按钮则仅更新当前模块），同时保留已登记的学校信任设备状态。

## 接入与提醒

雨课堂可在「设置 → 外部作业源」中通过扫码或网页登录接入；邮箱与日历支持配置对应的标准协议账号或客户端授权码；清华云盘与 GitLab 按页面提示完成认证即可连接。各模块的具体用法请参阅 [作业](homework.md)、[日程与同步](schedule-and-sync.md) 与 [分享与组织](sharing-and-organizations.md)。

日程与作业提醒需先开启操作系统的通知权限。在 Android 手机上，建议同时允许应用后台运行、开启精确闹钟权限并关闭省电限制，以确保锁屏后仍能准时收到提醒。手机系统的桌面小组件与应用内完整模式的白板组件各自独立管理；体验推送通知、NFC 触碰与本地文件下载等系统级能力时，请在安装好的原生客户端上直接操作验证。
