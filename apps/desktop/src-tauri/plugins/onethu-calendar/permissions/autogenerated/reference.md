## Default Permission

允许使用系统日历原生同步：
查询支持平台、请求日历权限、写入/清理 OneTHU 专属日历事件、移除该日历。

#### This default permission set includes the following:

- `allow-supported`
- `allow-request-permission`
- `allow-sync`
- `allow-remove-calendar`
